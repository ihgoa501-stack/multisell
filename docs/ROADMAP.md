# 凌镜 Owner 自用开发路线

> 更新时间：2026-07-11
> 当前阶段：Sprint 1，候选市场与独立反证闭环
> 产品边界：[SELF_USE_OPERATING_DIRECTION.md](SELF_USE_OPERATING_DIRECTION.md)

## 路线目标

发现或证伪一个真实付费需求：先比较并淘汰候选市场，由 Owner 批准一个“国家/地区 × 目标消费者 × 需求场景 × 销售渠道”，再形成有来源的假设并完成独立反证，最后用最小实验取得付款、签收、售后和最终贡献利润证据。所有 Sprint 都必须推动这条结果链，不再按已有平台、模块、页面或 Agent 数量扩张。

## Sprint 0：战略事实源归一

状态：✅ 已完成（2026-07-11）。

- 冻结双产品、外部 SaaS、多租户、计费、公共 API 和未经实证的平台扩张；
- 统一下单、有效成交、最终有效成交、预计利润和最终净利润词典；
- 将活跃 TODO 压缩为首轮真实实验。

验收：任何新 Agent 读取事实源后，都不会继续建设旧大教堂方向。

## Sprint 1：候选市场与独立反证闭环

状态：🚧 研究基础设施已可用：候选市场 `DemandCase`、八维研究证据、独立反证、三类 AI 输入契约、不可变研究输出快照、带日期研究导入、研究阶段确定性裁决、JWT 保护 API 与 Owner 六行决策页面已落地。账号内预检、完整交易状态机、不可变交易事件和实验草案仍待后续完成。

2026-07-11 公开来源研究及独立反证已完成：英国、美国保持 `hold + evidence_missing`，日本当前候选表述 `reject`，本轮没有值得申请账号权限的候选。页面导入的是已审阅输出，不在点击时重新联网。

同日第二轮改为“具体问题优先”：先审查地区、人群、具体场景、责任主体和消费品可解性，再决定是否允许进入渠道比较。美国野火烟霾与澳大利亚老年跌倒为 `evidence_missing`，美国家具倾倒与 England 严重潮湿为 `rejected`；本轮 0 个案件通过反证，因此不选择商品、不选择渠道、不申请权限、不花费。

- 建立候选市场、`DemandCase`、证据、反证、实验草案、事件与裁决；
- 平台连接器不得充当候选市场；已有账号只计入验证成本，不计入需求得分；
- 用确定性状态机阻止搜索、评论、榜单、加购和普通订单跨级冒充付款；
- 定义侦察、反证和数据现实三种独立 AI 输入契约；
- 保存原始 payload、来源、时间、地区、字段定义、解析版本和冲突；
- 输出六行 Owner 决策卡，不展示 Agent 投票或虚构置信度；
- 采集失败保持 unknown，关键证据缺失阻止实验批准。

验收：Owner 不需要日常抄数；每个假设有独立反证，任何结论可回到原始证据；真实交易前系统只能输出线索、证据不足、被污染、已驳回或可实验。

## Sprint 2：入围市场的真实只读数据预检

- 只对候选短名单需要的平台和数据源验证只读权限、字段、收款、费用和履约入口；
- 代码存在不能代替真实账号调用；
- 未授权或需要 listing/交易后才产生的数据明确标记；
- 只生成 Owner 授权卡，不执行外部写入。

验收：至少一个平台得到真实 `available` 或明确 `requires_owner_access` 证据，不虚构已开放能力。

## Sprint 3：自动研究与反证批次

- 三个独立 AI run 生成、反驳并审计最多 10 个真实来源假设；
- 只保留经过反证仍存活的案件；
- 最多输出 3 个值得请求更多只读数据的案件；
- 没有存活案件时明确结束本轮，不强行推荐。

验收：每个案件能说明已证明、未证明、最强反证、下一权限/成本与停止线。

## Sprint 4：Owner 批准的最小真实实验

- 另行冻结 SKU、价格、流量、终点、排除规则、预算、损失线和售后窗口；
- 采购、发布和广告分别由 Owner 批准；
- 记录付款、发货、签收、退货、争议、结算和全部实际成本；
- 晚到退款或费用自动重开裁决。

验收：至少 3 名非关联买家在至少 2 个自然日付款；只有售后闭合且最终贡献利润为正才称发现真实付费需求。

## Sprint 5：三轮后再自动化

连续三轮真实实验后，按重复耗时和损失影响排序，决定是否自动化采集、费用同步、评分、Listing 文案或广告数据。没有真实使用证据的能力继续冻结。

## 全程安全约束

自用不降低安全要求。真实发布、采购、广告、库存、价格、订单、退款和资金动作必须 Owner 批准、审计并可恢复；read-only、dry-run、sandbox 和 production 必须明确区分。
