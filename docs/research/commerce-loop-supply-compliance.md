# 跨境实物商品经营闭环（中段）：供应、合规、跨境准备与入库

> 研究范围：从已经形成“需求—规格线索”开始，到可销售库存完成入库为止；不限销售平台、国家或品类。
> 研究日期：2026-07-11。本文是经营流程与系统边界设计，不构成特定法域的法律、税务或报关意见。

## 一、结论先行

这一段不是“找到供应商 → 下单 → 发货”，而是连续八道可回退的风险闸门：

```text
需求—规格基线
→ 供应商发现与主体/能力验证
→ 打样与设计冻结
→ 成本、质量与可经营性确认
→ 目标市场合规与知识产权放行
→ 采购合同与订单生效
→ 生产控制、验货与放行
→ 进出口、运输与清关准备
→ 到货验收、隔离/放行与库存入账
```

真正的终点不是“货到了”，而是：**某一批次商品的身份、权属、成本、合规证据和质量状态均可追溯，并被授权人员放行为可销售库存。**

任何阶段发现的新事实，只能让商品前进、退回前序阶段修订，或终止；不能用平台允许上架、供应商承诺、一次样品合格或一张检测报告替代闸门。

## 二、全局边界与共同数据对象

### 2.1 必须先冻结的边界

每个商品机会必须先绑定以下变量，因为同一商品在不同组合下可能适用完全不同的规则：

- 产品身份：用途、用户年龄、材料、结构、电气/无线/化学属性、品牌与包装；
- 目标市场：销售国/地区和进口国，而非笼统的“海外”；
- 经营者角色：品牌所有人、制造商、出口商、进口商、授权代表、分销商分别是谁；
- 交易与物流模型：销售主体、进口记录方、Incoterms® 规则、仓储地点；
- 批次与版本：样品、材料、BOM、工艺、标签、说明书、包装的版本。

欧盟官方说明明确区分制造商、进口商和分销商责任；制造商需要识别适用规则、执行合格评定、建立技术文件，进口商则需确认这些工作已经完成，并核对标签与追溯信息。CE 只适用于特定法规覆盖的产品，不应给其他产品随意加贴，也不代表欧盟政府批准产品安全。[欧盟产品合规职责](https://europa.eu/youreurope/business/product-requirements/compliance/index_en.htm)；[欧盟委员会 CE 标识说明](https://single-market-economy.ec.europa.eu/single-market/goods/ce-marking_en)

### 2.2 贯穿全程的最小数据对象

1. `ProductSpecification`：功能、材料/BOM、关键尺寸、性能、缺陷定义、标签、包装、测试方法与版本；
2. `SupplierParty`：法定主体、工厂地点、实际制造能力、分包、银行账户、证照及验证来源；
3. `Sample`：样品唯一编号、版本、制作条件、测试结果、留样位置；
4. `ComplianceCase`：产品 × 目标市场 × 经营者角色的法规、标准、证据、责任人与有效期；
5. `IPClearance`：商标、外观、专利、版权/素材、许可与检索范围；
6. `CostModel`：采购、模具、检验、认证、包装、运输、保险、关税税费、仓储及风险准备；
7. `PurchaseContract/PO`：合同、订单、变更、付款、交货与违约规则；
8. `ProductionLot`：批号、生产日期、BOM/工艺版本、数量、检验与不合格处置；
9. `Shipment`：箱单、商业发票、原产地、HS 归类、申报价值、运输单据及监管文件；
10. `InventoryLot`：到货差异、隔离/放行状态、库位、批次单位成本和证据链。

## 三、八阶段闭环

## 阶段 1：供应商发现与主体/能力验证

**输入**

- 已批准的需求—规格线索、预估数量/频率、目标成本和交期；
- 产品/市场初步风险等级与禁止条件；
- 供应商候选来源。

**活动**

1. 用法定企业登记机关、许可证签发机关、税务/海关公开渠道（视国家而定）核验主体名称、登记号、状态、地址、法定代表和许可；
2. 区分贸易商、品牌方与实际工厂；核对工厂地址、设备、关键工序、产能、分包商和旺季负载；
3. 对银行收款账户与合同主体做一致性核验；变更账户须独立二次验证；
4. 收集质量体系、历史批次、主要缺陷/召回、交付表现及客户引用，但证书要向签发/认可机构复核真实性与范围；
5. 按风险决定远程审查、现场审核或第三方审核，并建立合格供应商清单和持续绩效记录。

ISO/IAF 关于 ISO 9001 外部供方的审核指导将“批准的外部供方清单、按既定准则下单、供方绩效监控、验证要求已满足以及基于风险决定控制强度”列为审核关注点。这支持建立持续供方治理，而非只做一次资质收集。[ISO/IAF 外部供方指导](https://committee.iso.org/files/live/sites/tc176/files/documents/ISO%209001%20Auditing%20Practices%20Group%20docs/Auditing%20to%20ISO%209001%202015/APG-ExternalProviders2015.pdf)

**输出**

- 经来源验证的供应商档案；
- 制造能力与分包地图；
- 风险评级、审计发现、整改计划；
- 可进入打样的短名单（通常保留备选，不形成单点依赖）。

**闸门**

- 法定主体、实际生产地点、收款主体可一致解释；
- 关键工序、产能、质量控制及高风险资质得到证据支持；
- 重大问题已关闭，或有 Owner 接受的书面残余风险；
- 供应商未被仅凭平台徽章、销售话术或无法验证的证书放行。

**失败/回退**

- 主体/账户异常、拒绝披露实际工厂、能力无法验证：淘汰并转备选；
- 能力可补救：要求整改后复审；
- 规格超出供应能力：退回需求—规格阶段拆分或降级，但不得默默改规格。

**指标**

- 资质来源核验完成率、主体/账户不一致率；
- 审计重大问题关闭率与周期；
- 合格备选供应商数量、关键工序单点依赖率；
- 后续样品一次通过率、供应商准时完整回复率。

**责任边界**

- 采购/寻源负责发现、商务信息与主体材料；质量负责能力审计；合规负责人定义高风险资格；财务独立核验账户；最终准入由有授权的业务责任人批准。
- “供应商合格”只表示可以继续验证，不表示商品、批量生产或目标市场已经合规。

## 阶段 2：打样与设计冻结

**输入**

- 经版本控制的规格、缺陷分类与验收方法；
- 合格供应商短名单；
- 预计适用的安全/标签/包装要求。

**活动**

1. 发出样品订单，明确样品是否为手板、工程样、产前样或量产同线样；
2. 为每个样品绑定供应商、BOM、材料批次、工艺、日期和版本，保存照片/测量值及实体留样；
3. 执行功能、尺寸、耐用、误用、包装运输和初步合规测试；关键测试应使用合适且被目标法规接受的实验室；
4. 记录每项偏差、根因、修改及重新测试范围；
5. 批准最终“金样/封样”，冻结规格、BOM、标签、说明书、包装和变更控制。

美国 CPSC 明确提示：法规与材料决定所需测试；儿童产品须由 CPSC 接受的第三方实验室测试，而且选择实验室或取得通过结果并不转移制造商/进口商的最终责任。[CPSC 实验室选择](https://www.cpsc.gov/FAQ/Selecting-a-Third-Party-Laboratory)；[CPSC 测试与认证](https://www.cpsc.gov/old/Business--Manufacturing/Testing-Certification)

**输出**

- 测试完整、可追溯的封样；
- 冻结的产品规格包与检验作业书；
- 差异/整改记录及批准人；
- 量产变更控制规则。

**闸门**

- 样品满足所有关键功能、安全和关键尺寸要求；
- 量产可复制性得到证据支持，且封样来自已知工艺/BOM；
- 未关闭的偏差已明确接受人、范围和原因；
- 任一影响安全、合规、关键功能或客户承诺的变更必须重新评估，不得由供应商自行替换。

**失败/回退**

- 可修正：更新规格并重新打样；
- 反复失败：回到供应商选择；
- 需求本身不可制造或成本失真：退回商品机会评估或终止。

**指标**

- 打样轮数、一次通过率、每轮周期和成本；
- 关键缺陷数、变更后重新测试覆盖率；
- 封样与量产一致率。

**责任边界**

- 产品负责人定义用途与体验；工程/质量定义可测规格；合规负责人决定法规测试；供应商负责依冻结资料制造。样品批准不等于量产批放行。

## 阶段 3：成本、质量与可经营性确认

**输入**

- 冻结规格/封样；供应商阶梯报价、MOQ、模具和付款条件；
- 包装尺寸重量、路线和目标市场税费假设；
- 预计缺陷、损耗、退货与库存周期。

**活动**

1. 建立版本化的完全到岸成本：货价 + 模具/NRE + 检测认证摊销 + 包装 + 国内集运/出口 + 国际运输/燃油/保险 + 关税及不可抵扣税费 + 清关/港杂 + 入库质检 + 仓储 + 资金与损耗准备；
2. 用敏感性分析覆盖汇率、运价、关税归类、MOQ、良率、延误和退货；
3. 设定关键/主要/次要缺陷定义、检验方法、抽样方案、可接受阈值和拒收后的处置；
4. 以试产或小批验证产能、节拍、良率和包装，而非从手工封样直接跳到大货。

ISO 2859-1:2026 是按属性进行逐批验收抽样的国际标准，以 AQL 索引样本量及接收/拒收阈值，并包含正常、加严、放宽/跳批的切换思想。AQL 是统计抽样工具，不是“允许供应商故意制造某比例缺陷”，也不能替代法规要求的逐件或特定测试。[ISO 2859-1:2026](https://www.iso.org/standard/85464.html)；[ISO 28590:2017 选用指导](https://www.iso.org/standard/64622.html)

**输出**

- 基准、悲观和压力情景成本模型；
- 质量计划、缺陷目录、检验规范、批次判定规则；
- 试产报告与更新后的商业可行性结论。

**闸门**

- 悲观情景仍在 Owner 批准的最大亏损/现金暴露内；
- 关键缺陷规则、检验权限和拒收责任已书面化；
- 试产证明量产过程能稳定复制封样；
- 尚未确认的 HS、税费或合规成本被列为风险，不伪装成确定利润。

**失败/回退**

- 成本过高：重谈、改包装/路线/数量或回到规格设计；所有改变触发合规与样品影响评估；
- 过程能力不足：供应商整改、再试产或更换供应商；
- 风险超过上限：终止机会。

**指标**

- 报价到完全到岸成本的偏差；实际/预测单位成本偏差；
- 试产良率、关键/主要缺陷率、返工率；
- 现金转换周期、MOQ 覆盖天数、压力情景最大损失。

**责任边界**

- 采购拥有报价真实性；质量拥有缺陷与检验规则；物流/报关提供运输与税费依据；财务拥有成本模型；Owner 批准现金暴露和残余风险。

## 阶段 4：目标市场合规与知识产权放行

**输入**

- 冻结产品、BOM、标签、包装、营销主张；
- 目标市场与经营者角色；
- 供应商和实验室材料；品牌、外观、图片、文案与许可。

**活动**

1. 建立“产品 × 市场 × 角色”法规矩阵：产品安全、化学/材料、能效/环保、电气/无线、食品/药品/化妆品、儿童用品、标签语言、生产者责任、注册和召回义务；
2. 判断是否需要指定实验室、公告/认证机构、当地责任主体、注册、技术文件、符合性声明或证书；
3. 将测试报告逐项映射到准确 SKU、BOM、版本、适用标准、实验室资质、报告日期和目标市场；
4. 检查商标、外观、专利、版权/图片和包装素材，记录检索式、法域、类别、日期及法律复核；
5. 建立上市后事故、投诉、追溯、停止销售、撤回/召回和监管报送方案。

WIPO 全球品牌数据库覆盖马德里国际商标及参与的国家/地区数据库，但 WIPO 也明确建议同时检索相关国家/地区知识产权局登记册，所以“WIPO 无结果”不能视为全球清权完成。[WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database)

美国 CPSC 说明，受规则约束的一般用途消费品须由制造商或进口商根据逐件测试或合理测试计划签发 GCC；海外制造商品通常由美国进口商签发，证书须随每批货，并在要求时提供给监管/海关。供应商报告可作为依据的前提包括尽职核验，某些最终成品测试不能由部件报告替代。[CPSC 一般用途产品认证](https://www.cpsc.gov/Business--Manufacturing/Testing-Certification/General-Use-Products-Certification-and-Testing)

**输出**

- 适用法规/标准与责任矩阵；
- 完整技术证据包（测试、声明、证书、注册、标签、追溯）；
- IP 检索与许可档案；
- 上市后监测/召回方案；
- 有效期、变更触发器和重新评估日期。

**闸门**

- 所有强制要求均有“适用/不适用”的可解释结论和权威来源；
- 每份证据与实际 SKU/BOM/批次一致，签发机构与范围可验证；
- 法定责任主体已书面接受角色；
- 高风险 IP 由合格专业人员复核；
- 任何关键缺口都不能用免责声明或平台审核通过覆盖。

**失败/回退**

- 测试失败：纠正设计/BOM，重新打样并重测；
- 缺少当地责任主体/注册：补齐后再审；
- 商标/外观/专利风险：更名、重设计、取得许可或终止；
- 市场不经济：缩减目标市场，而不是“一套证据全球通用”。

**指标**

- 强制要求覆盖率、证据与 SKU/版本匹配率；
- 测试一次通过率、合规补救周期/成本；
- 到期证据提前预警率；IP 高风险未结项数；
- 上市后安全投诉、监管扣留、召回率（滞后指标）。

**责任边界**

- 合规负责人维护矩阵，法务/IP 专业人员作高风险判断；实验室只对测试范围和结果负责；制造商/进口商等法定主体不能把最终责任外包给供应商、平台或实验室。

## 阶段 5：采购合同与订单生效

**输入**

- 已放行规格、封样、质量计划和合规证据要求；
- 批准的成本、数量、资金上限与交付计划；
- 经验证的合同/收款主体。

**活动**

1. 签订主采购/国际货物买卖合同并下 PO，确保合同、PO、规格附件、封样和变更记录层级清晰；
2. 明确产品/BOM/包装、数量容差、价格、付款里程碑、所有权与风险转移、交付地点/日期、Incoterms® 2020 具体规则及命名地点；
3. 约定检验/测试、合规文件、变更和分包审批、知识产权/模具权属、保密、可追溯与记录保存；
4. 约定延误、短装、缺陷、返工/补货/退款、召回与第三方索赔、保险、终止、不可抗力、适用法律与争议解决；
5. 付款与生产放行分离，关键里程碑须有证据和授权审批。

ICC 说明 Incoterms® 2020 的作用是分配买卖双方在交付中的成本、风险与义务；它不能替代完整买卖合同。ICC 国际销售示范合同则以具体条件和一般条件承载更完整的交易安排，并可选入 11 种 Incoterms® 2020 规则。[ICC Incoterms® 2020](https://iccwbo.org/business-solutions/incoterms-rules/incoterms-2020/)；[ICC 国际销售示范合同](https://iccwbo.org/business-solutions/model-contracts-clauses/icc-model-international-sale-contract/)

**输出**

- 双方签署且附件完整的合同/PO；
- 付款、生产、检验、交付里程碑；
- 责任/RACI、索赔和争议路径；
- 受控的订单版本和变更日志。

**闸门**

- 合同主体、收款账户、规格版本和封样一致；
- 质量、合规、交付、风险转移和不合格救济可执行；
- 任何口头变更已进入书面变更控制；
- 预付款和最大风险敞口在授权额度内。

**失败/回退**

- 条款无法接受：重新谈判或转备选；
- 商业变化：回到成本/现金闸门；
- 规格/材料变化：回到打样、质量和合规影响评估。

**指标**

- 未受控 PO 变更率、附件缺失率；
- 预付款暴露、合同签署周期；
- 索赔回收率、供应商违约次数。

**责任边界**

- 采购推动谈判；质量/合规拥有专业附件；财务控制付款；法务审查适用法律和救济；授权人批准合同。Incoterms 不解决产品合规、付款、所有权、违约和争议的全部问题。

## 阶段 6：生产控制、验货与批次放行

**输入**

- 生效合同/PO、冻结规格/封样、质量计划；
- 批次计划、原料/BOM、关键工序和批准分包商；
- 检验预约与放行权限。

**活动**

1. 生产前会议确认版本、材料、标签、包装、产量与关键控制点；
2. 视风险进行来料、首件、生产中和出货前检验；高风险特性按法规/工程要求逐件或专项测试；
3. 抽样须在明确批次、随机性、检验水平、AQL、Ac/Re、缺陷等级的方案下执行；
4. 不合格品隔离，记录偏差、根因和纠正预防措施；返工批必须重新检验；
5. 将检验报告、照片/视频、测试原始数据、批号及封样关联；由买方授权人发出装运放行。

**输出**

- 完整批次制造与检验记录；
- 接收、返工、降级或拒收决定；
- 不合格与 CAPA 档案；
- 可装运批次及数量清单。

**闸门**

- 批次身份、数量和规格版本明确；
- 关键缺陷为零或满足更严格法定规则，抽样结果符合预定 Ac/Re；
- 返工、偏差和变更均经批准且完成必要重测；
- 未获书面放行不得装运，付款不得自动等同质量接收。

**失败/回退**

- 批次拒收：隔离→根因→返工/重制→重新检验，或取消/索赔；
- 未授权材料/工厂/分包变化：暂停，退回样品和合规重评；
- 系统性过程失控：供应商整改/加严检验或重新寻源。

**指标**

- 首检通过率、批次拒收率、关键/主要/次要缺陷率；
- CAPA 关闭周期、重复缺陷率；
- 封样/BOM 偏离率、按期完成率；
- 检验后到装运的时间与换货风险窗口。

**责任边界**

- 供应商负责过程和自检；独立检验方提供事实，不替买方决定商业接收；质量负责人作质量放行；合规负责人处理法规相关偏差；采购执行合同救济。

## 阶段 7：进出口、运输与清关准备

**输入**

- 已放行批次、合同/PO 与 Incoterms；
- 产品、材料、用途、价格、原产加工事实；
- 目标路线、进口记录方、承运/货代/报关服务商与合规文件。

**活动**

1. 在装运前确认出口/进口资格、禁限运、许可证、制裁/受限方、产品监管、危险品和包装木材等要求；
2. 确定 HS 归类、原产地、海关估价、关税/税费和优惠原产资格；高不确定项目申请主管海关预裁定；
3. 使商业发票、箱单、合同、原产地文件、运输单据、保险、许可证/合规证书及申报数据相互一致；
4. 明确订舱、包装、唛头、装箱、保险、出口申报、进口清关、查验、税费、滞箱滞港和最终交付责任；
5. 采用装运前文件审计和尽可能的预申报/预处理，保留原始证据和沟通记录。

WCO 的 HS 工具用于商品归类并与原产地和估价工具交叉使用；WCO 还指出，进口前预裁定可对归类、原产地和估价提供具有约束力的确定性。[WCO HS FAQ / Trade Tools](https://www.wcoomd.org/en/faq/harmonized_system_faq.aspx?p=1)；[WCO 估价预裁定](https://www.wcoomd.org/en/topics/valuation/instruments-and-tools/advance-rulings-for-valuation.aspx)

WTO《贸易便利化协定》要求成员公布进口、出口、过境程序、税费、归类/估价、原产地、禁限和处罚信息；同时覆盖预裁定、到货前处理、单一窗口和海关合作。协定列出的典型支持文件包括商业发票、箱单、原产地证书和提单。[WTO《贸易便利化协定》正文](https://www.wto.org/english/docs_e/legal_e/tfa_e.htm)

**输出**

- 经复核的贸易合规/清关档案；
- HS、原产地、估价及依据（必要时含预裁定）；
- 一致的装运文件包、订舱与保险；
- 各节点责任、预计税费、ETA 与异常预案。

**闸门**

- 进口记录方和法定责任主体已确认并有资格；
- 禁限、许可证、产品与危险品要求已经放行；
- 归类、原产、估价有证据，文件数据一致；
- 未完成许可证/证书或身份不明的商品不得“先发再补”。

**失败/回退**

- 文件差异：装运前纠正并重新审批；
- 归类/原产/估价重大不确定：申请预裁定或专业复核；
- 禁运/缺证/无法合法进口：改合规市场/路线（合法前提下）或停止；
- 海关查验/扣留：进入异常案件，隔离相关批次并保存证据，不得重复提交不一致信息。

**指标**

- 文件一次正确率、预申报完成率；
- 清关时长、查验/扣留率、补税/罚款率；
- 预计与实际关税税费偏差；
- 滞箱滞港、运输损坏和准时到仓率。

**责任边界**

- 出口商/进口商承担各自法定申报责任；报关行、货代和承运人是专业执行方但不自动接管货主责任；采购/物流不能自行覆盖合规否决。WCO SAFE 以风险分析和海关—企业合作强化端到端安全，说明供应链安全也应落实到经营者日常程序，而不是只交给运输商。[WCO SAFE 2025](https://www.wcoomd.org/-/media/wco/public/global/pdf/topics/facilitation/instruments-and-tools/tools/safe-package/safe-framework-2025_en.pdf)

## 阶段 8：到货验收、隔离/放行与库存入账

**输入**

- 实际到货、运输/清关记录；
- PO、装箱单、批次放行和合规档案；
- 到货检验规范、库位和成本分摊规则。

**活动**

1. 在交接时记录封条、箱体、温湿度/冲击（适用时）、数量和可见损坏，及时保留承运索赔证据；
2. 按 PO/箱单做数量、SKU、批号、序列号、有效期和标签核对；
3. 新品/高风险/异常货先进入质量隔离区，进行到货抽检或必要复测；不得在检验完成前成为可销售库存；
4. 对短装、错货、损坏、标签/证据缺失和测试失败建立不合格案件，物理与系统状态同步隔离；
5. 通过后由授权人放行，建立库存批次、库位、可售状态、完全到岸单位成本及完整证据链接；保存留样；
6. 将实际成本、交期和缺陷反馈给供应商评分、成本模型及下一批采购决策。

**输出**

- 收货差异和到货检验报告；
- 隔离、放行、退货、返工或索赔决定；
- 可销售库存批次与单位实际到岸成本；
- 供应商、物流及预测偏差的闭环反馈。

**闸门**

- 实物、系统记录、PO、清关和证据包能够逐批对应；
- 数量/质量/标签/合规证据满足接收条件；
- 库存权属、可售状态、成本和库位已由授权人确认；
- 隔离库存不能被分配、上架或发货。

**失败/回退**

- 可补证但实物安全：保持隔离直至证据审查完成；
- 损坏/缺陷：分拣、返工、退运/销毁（依法）、索赔，并评估是否触发扩大抽检；
- 发现批量系统性或安全问题：停止放行相邻批次，回到生产、合规或物流根因调查；
- 成本显著超限：不改变已发生事实，回到下一采购轮次的商业闸门。

**指标**

- 收货差异率、到货损坏率、到货检验失败率；
- 隔离库存数量/金额/平均天数；
- 可售放行周期、批次追溯完整率；
- 实际到岸成本偏差、供应商/承运人索赔回收率。

**责任边界**

- 仓库负责保管、计数和物理状态；质量负责检验及质量放行；合规负责证据缺口/安全问题；财务负责实际成本；库存系统只能反映授权决定，不能自行把“已收货”转换成“可销售”。

## 四、跨阶段回退与变更规则

以下变化必须触发影响评估，不能只改采购单：

| 变化 | 至少回退到 | 必查事项 |
|---|---|---|
| 材料、BOM、配方、关键零件 | 打样 | 功能、安全、法规测试、成本、标签 |
| 工厂、关键工序或分包商 | 供应商验证 | 能力、体系、产地、质量与合规证据 |
| 结构、用途、年龄段、营销主张 | 打样/合规 | 适用法规、误用风险、说明与测试 |
| 品牌、图案、包装和文案 | IP/合规 | 商标、版权、标签与消费者主张 |
| 目标市场或进口主体 | 合规 | 法规、证书/注册、税务海关与召回责任 |
| 数量、MOQ、路线、Incoterms | 成本/合同 | 现金暴露、风险转移、运输、税费 |
| 发现关键/安全缺陷 | 生产/合规 | 隔离范围、根因、重测、停止销售/召回 |

系统应把“变更 → 受影响对象 → 重新审批 → 新版本”做成不可绕过的链。旧证据不得自动继承给新 SKU、BOM、工厂或市场。

## 五、不能被八阶段切断的贯穿风险

这些事项没有单独的“一次性完成”阶段，而应从立项持续到退出：

| 贯穿维度 | 进入采购前 | 生产/跨境中 | 入库及销售后 | 退出条件 |
|---|---|---|---|---|
| 主体、资质、制裁与保险 | 核验所有合同/制造/进口主体、必要许可及产品责任险承保范围、地域、限额和除外 | 监测主体/账户/许可变化，确保高风险活动和运输保险生效 | 保留有效保单与事故通知路径 | 责任存续期、索赔期和记录保存期结束 |
| IP 与授权 | 商标、专利、外观、版权、模具和素材清权 | 监控未经批准的复制、换标、分包和泄密 | 监测侵权投诉、下架及许可到期 | 停止使用、处置带标库存/模具并完成证据留存 |
| 产品责任、追溯与召回 | 定义法定责任人、批号/序号和召回计划 | 保证原料—工艺—批次—运输证据不断链 | 投诉/事故分级、停止销售、通知、撤回/召回、效果验证 | 法定责任和记录期限届满；未结事故不得关闭 |
| 售后备件与质保 | 将质保承诺、备件品种/数量、维修或替换路径计入成本和合同 | 锁定关键备件版本、供应与质量 | 监测故障率、备件消耗、维修时效和质保准备金 | 最后一件商品质保/法定责任期结束并处置剩余备件 |
| 供应中断 | 识别单一工厂、模具、材料、航线和关键人员；设替代源/安全时间 | 监控产能、灾害、停工、质量失控及物流拥堵 | 基于真实消耗和风险调整安全库存 | 转供应商时完成新一轮验证、打样与合规，不可直接复制批准 |
| 汇率、运价与贸易政策 | 为汇率、关税、反倾销/制裁、税务和监管变化做压力情景 | 在付款、订舱和申报节点重新估算暴露 | 用实际差异回写成本与补货决策 | 超出 Owner 风险限额时暂停补货或退出，而非沉没成本加码 |
| 包装环保与 EPR | 按销售国识别包装、电子电气、电池等生产者责任、注册、标识和报告义务 | 保留材料重量/组成、供应商声明和包装批次 | 申报投放量、缴费、回收/报告并监测法规变化 | 停售不当然终止历史报告、费用和记录义务 |
| 退出与库存处置 | 预先定义停止补货、降价、转售、退供、返工、捐赠、销毁的条件和授权 | 一旦触发退出，停止新增不可逆承诺并隔离待定库存 | 处置须满足产品安全、IP、环保、海关/税务与数据记录要求 | 库存、模具、备件、许可、索赔和法定义务全部结清 |

其中产品追溯不是仓库内部编号问题。欧盟官方产品合规指南要求制造商/进口商核对产品类型、批号或序列号以及责任主体联系信息，并在不合规时采取纠正、撤回或召回措施。[欧盟产品合规职责](https://europa.eu/youreurope/business/product-requirements/compliance/index_en.htm) 美国 CPSC 亦要求儿童产品及包装在可行时带永久追踪信息，使召回能够定位生产信息。[CPSC 测试与认证](https://www.cpsc.gov/old/Business--Manufacturing/Testing-Certification)

贯穿风险应各自拥有：责任人、下一复核日、监测信号、阈值、预案、证据与关闭条件。它们不能在某一闸门打上“完成”后永久失效。

## 六、系统开发时应实现的决策状态，而非页面堆叠

建议统一状态机：

```text
draft
→ evidence_pending
→ review_pending
→ approved | approved_with_conditions
→ executed
→ verified
→ closed

任何节点均可：rework_required | quarantined | rejected | cancelled
```

每次闸门决定至少记录：对象与版本、决定、依据、证据来源、责任人、审批人、时间、有效期、条件、残余风险和下一步。AI 可以搜集、比对、预警和建议，但不得：

- 伪造主体/证书核验结果；
- 代替法定责任主体签发声明或申报；
- 自动接受安全/合规偏差；
- 自动付款、放行装运或把隔离库存转为可售；
- 将一个市场、SKU、BOM 或批次的证据无审查复用到另一个对象。

## 七、Owner 级最小仪表盘

无需展示所有操作字段，Owner 只需看到跨阶段的真实风险：

1. 每个机会当前闸门、阻塞原因、责任人和预计解除日期；
2. 已投入现金、下一笔不可逆支出和最坏损失；
3. 供应商单点依赖、未关闭重大质量问题；
4. 按目标市场分列的强制合规/IP 缺口与证据到期；
5. 生产批次接收/拒收、在途异常和清关风险；
6. 隔离库存金额、可售库存金额和实际到岸成本偏差；
7. 需要 Owner 决定的残余风险，而不是需要 Owner 判断技术细节。

再增加三个贯穿视图：保险/许可/证书的覆盖与到期，售后质保及召回准备，供应中断与贸易政策压力情景。退出商品要单列未结库存、备件、模具、许可、EPR/税务申报和索赔，直到全部清账。
