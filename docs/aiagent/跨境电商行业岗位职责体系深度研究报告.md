> 研究目的：为AI Agent系统设计提供跨境电商行业完整的岗位分类、职责、技能、工具及协作关系参考。

> 数据来源：BOSS直聘、猎聘、Indeed、LinkedIn、AMZ123、知无不言、亚马逊全球开店官方资料等公开职位信息整合分析。

### 2.1 运营类岗位

---

#### 1.1 亚马逊运营专员/主管

**核心职责（10条）：**

1. **Listing创建与优化**：撰写产品标题(Title)、五点描述(Bullet Points)、产品描述(Description)、搜索词(Search Terms)；进行A+页面（EBC/A+ Content）设计与内容制作；管理产品图片、视频等视觉素材
2. **关键词研究与策略**：使用工具进行关键词调研和反查竞品关键词，建立关键词词库；持续优化Search Terms和后端关键词以提升自然搜索排名
3. **广告投放管理**：创建和管理SP（Sponsored Products）、SB（Sponsored Brands）、SD（Sponsored Display）广告活动；设置广告预算、竞价策略(Bidding Strategy)、关键词匹配类型(广泛/词组/精准)；进行否定关键词管理
4. **库存管理与销量预测**：根据销售趋势、季节性、广告投放计划制定补货计划；管理FBA库存（安全库存、周转率、冗余库存清理）；创建FBA发货计划(Shipment Plan)
5. **竞品与市场分析**：监控竞品价格、排名、Review变化；分析类目趋势和市场容量；利用工具跟踪竞品关键词排名和广告策略
6. **账号健康管理**：监控Account Health（ODR、有效追踪率、迟发率、订单缺陷率）；处理绩效通知(Performance Notifications)和A-to-Z索赔
7. **Review与Feedback管理**：通过合规方式获取产品评价；处理差评Review的跟进与改善措施；维护店铺Feedback评分
8. **促销活动策划与执行**：设置Coupon、Lightning Deals、7-Day Deals、Best Deals；制定促销价格策略；参与Prime Day、Black Friday等平台大促活动
9. **数据分析与报表**：分析业务报告(Business Reports)中的流量、转化率、销售额等关键指标；制作日报/周报/月报；使用数据驱动决策优化运营策略
10. **品牌注册与保护**：进行Amazon Brand Registry；管理品牌旗舰店(Amazon Store)；利用品牌分析工具(Brand Analytics)获取市场洞察

**关键技能：**

| 技能类别 | 具体技能 |
|---------|---------|
| **语言能力** | 英语CET-4/6级及以上（必备）；日语N2/JLPT（日本站）；德语B2（欧洲站） |
| **平台操作** | 精通Seller Central后台全功能操作；熟悉Vendor Central（如有VC账号） |
| **数据分析** | Excel高级函数（VLOOKUP、PivotTable、数据透视表）；基础SQL/BI工具 |
| **广告投放** | SP/SB/SD广告架构设计；ACOS/ROAS优化方法论；竞价策略管理 |
| **Listing优化** | 文案撰写技巧；SEO思维；A+页面设计能力；基础PS/Canva能力 |
| **库存管理** | FBA库存管理逻辑；IPI分数优化；库存健康指标管理 |

**常用工具：**

|---------|------|

| Keepa | 价格历史追踪、销售排名监控、Buy Box分析 |
| Seller Sprite (卖家精灵) | 关键词反查、竞品监控、广告分析 |

#### 1.2 Shopee/Lazada/TikTok Shop运营

**核心职责（8条）：**

1. **店铺搭建与基础运营**：负责Shopee/Lazada/TikTok Shop店铺开设、装修、产品上架、价格设置、库存同步
2. **平台活动报名与执行**：参与平台大促活动（9.9、11.11、12.12等）；设置店铺优惠券、运费促销、捆绑销售、加购优惠等营销工具
3. **Listing本地化优化**：针对东南亚/拉美市场进行多语言标题和描述优化；管理产品主图、视频及尺码表等本地化信息
4. **关键词广告投放**：管理Shopee关键词广告/Lazada超级推广；优化商品搜索排名；管理搜索广告竞价与预算
5. **直播与短视频运营**（TikTok Shop特有）：策划和执行TikTok直播带货；管理达人合作（Affiliate/联盟营销）；短视频内容策略和制作跟进
6. **店铺评分管理**：维护店铺评分（Shop Rating）、聊聊回复率（Chat Response Rate）、发货时效；降低退货退款率
7. **竞品监控**：监控同行定价、促销策略、新品动态；收集分析市场价格信息
8. **物流方案选择**：选择Shopee/Lazada官方物流(SCS/LGS)或第三方物流；管理海外仓/本地仓发货方案

**关键技能：**

- 东南亚市场理解（文化、消费习惯、节日促销周期）
- 小语种能力（泰语/越南语/印尼语/菲律宾语加分）
- 直播运营经验（TikTok Shop方向）
- 多店铺/多站点并行管理能力

**常用工具：**

#### 1.3 独立站运营（Shopify/WooCommerce）

**核心职责（8条）：**

1. **独立站搭建与维护**：使用Shopify/WooCommerce/Shoplazza搭建品牌独立站；管理网站主题、插件、支付网关、物流配置
2. **网站体验优化**：优化网站加载速度、移动端适配；A/B测试落地页(Landing Page)转化率；优化购物车和结算流程
3. **流量获取与转化**：对接Facebook Ads/Google Ads/TikTok Ads广告账户；配合广告团队优化转化追踪（Pixel/Conversion API设置）
4. **产品页面与内容管理**：创建高质量产品详情页；管理产品分类、标签、变体；制作博客内容和SEO友好页面
5. **促销与会员体系**：设置折扣码(Discount Code)、购物车挽救(Abandoned Cart Recovery)；搭建会员忠诚度(Loyalty Program)体系
6. **订单与履约管理**：对接ERP处理订单；协调仓储物流发货；管理退换货流程
7. **数据监控与分析**：使用Google Analytics/Shopify Analytics监控流量来源、转化漏斗、用户行为；制作运营报表
8. **支付与多币种管理**：配置PayPal/Stripe/Shopify Payments等多支付方式；管理多币种定价和汇率

**关键技能：**

- Shopify/WooCommerce平台深度操作能力
- 基础的HTML/CSS修改能力
- Google Analytics数据分析
- CRO（转化率优化）方法论
- 基础SEO知识

**常用工具：**

#### 1.4 全渠道运营/运营经理

**核心职责（8条）：**

1. **多平台运营统筹**：协调管理Amazon、Shopee、Lazada、独立站、eBay、速卖通等多渠道店铺运营
2. **渠道策略制定**：根据各平台特点和目标市场，制定差异化的产品策略、定价策略和促销策略
3. **销售目标管理**：制定年度/季度/月度销售目标和预算；分解各渠道/各品类的KPI指标
4. **产品矩阵规划**：统筹各渠道产品线上架策略；管理新品上市(GTM)流程；处理滞销品清仓
5. **团队管理与赋能**：搭建和培训运营团队；制定SOP标准作业流程；建立绩效考核体系
6. **品牌一致性管理**：确保各渠道品牌形象、定价策略、产品信息的一致性
7. **财务与利润管控**：监控各渠道利润（毛利率、净利率、广告费比）；制定渠道费用预算
8. **平台关系维护**：对接平台客户经理(Account Manager)；争取平台活动资源和流量扶持

**关键技能：**

- 3-5年跨境电商多平台运营经验
- 团队管理能力（5-20人团队）
- 财务分析和利润管控能力
- 战略规划与执行能力

### 2.2 产品与供应链类岗位

---

#### 2.1 选品专员/产品开发

**核心职责（9条）：**

1. **市场调研与分析**：通过工具和数据分析市场容量、搜索量趋势、季节性波动；识别蓝海市场和细分机会品类
2. **产品机会识别**：分析消费者痛点、产品差评点、改进空间；寻找差异化切入机会
3. **竞品分析**：研究BSR榜单、竞品定价区间、利润空间；分析头部卖家的产品策略
4. **产品可行性评估**：评估产品毛利率（目标毛利率≥30-40%）、物流成本、关税成本；计算ROI和回本周期
5. **供应链寻源**：通过1688/阿里巴巴国际站/行业展会寻找供应商；评估工厂资质和能力
6. **样品管理与测试**：协调打样、样品测试、质量评估；组织内部评审会议
7. **产品生命周周期管理**：规划产品上架时间节点；管理新品开发进度；制定产品退市计划

5. **资源获取**：向集团争取资源支持；管理事业部预算
6. **组织能力建设**：打造事业部核心能力和竞争壁垒
7. **战略汇报**：向集团高层汇报事业部战略和经营结果

### 3.3 关键信息流详细说明

#### 信息流1：选品信息 → 运营 → 采购

```
选品专员（输出）
  ├─ 选品报告（市场容量/竞品分析/利润测算）
  ├─ 产品规格需求
  └─ 目标售价和成本预算
        │
        ▼
运营专员（评审 + 执行）
  ├─ 确认选品方向和市场策略
  ├─ 细化Listing需求和关键词策略
  └─ 向采购下达产品采购需求
        │
        ▼
采购专员（执行）
  ├─ 按需求寻找供应商
  ├─ 样品采购和打样
  └─ 反馈采购成本和交期
```

#### 信息流2：运营 → 广告投放 → 数据分析

```
运营专员 → 广告专员
  ├─ 产品上架信息（ASIN/Listing状态）
  ├─ 广告预算和ACOS目标
  ├─ 促销活动计划
  └─ 关键词词库
        │
        ▼
广告专员 → 运营专员
  ├─ 广告数据报表（ACOS/ROAS/TACOS）
  ├─ 搜索词和关键词建议
  ├─ 广告优化建议
  └─ 竞品广告策略洞察
        │
        ▼
数据分析师
  ├─ 综合运营+广告+财务数据
  └─ 输出商业洞察报告
```

#### 信息流3：客服 → 选品/运营/品质（VOC闭环）

```
客服专员（收集客户声音）
  ├─ 产品高频问题/痛点
  ├─ 退货原因分类统计
  ├─ 差评内容分析
  └─ 客户需求与建议
        │
   ┌────┼────┬────────┐
   ▼    ▼    ▼        ▼
 选品  运营  品质    美工
 │     │     │        │
 ├─ 下 ├─ 修改 ├─ 品 ├─ 优化
 │  代 │  Listing│  质 │  图片
 │  产 │  描述  │  改 │  说明
 │  品 │        │  善 │
```

#### 信息流4：运营 → 供应链 → 财务

```
运营专员 → 供应链/物流 → 财务
  │           │              │
  ├─ 销售预测 ├─ 采购成本  ├─ 收入核算

```

## 四、AI Agent应用场景蓝图

基于上述岗位职责和协作关系分析，以下为各岗位领域的AI Agent优先应用场景建议：

### 4.1 高优先级（高频、标准化程度高的任务）

| 岗位 | AI Agent应用场景 | 预期价值 |
|------|-----------------|---------|
| 运营 | 关键词研究自动化、竞品数据监控、Listing健康诊断、库存预警 | 减少80%重复数据工作 |
| 广告 | 广告竞价自动调整、搜索词自动否定、预算智能分配 | ACOS降低15-25% |
| 客服 | AI客服机器人（售前+售后）、自动邮件回复、情绪识别和升级路由 | 减少60-80%重复咨询 |
| 财务 | 自动对账、利润自动核算、异常交易自动预警 | 财务效率提升3-5倍 |
| 选品 | 市场机会扫描、竞品分析报告自动生成、利润测算自动化 | 选品效率提升5倍 |

### 4.2 中优先级（需要多轮交互或一定判断力的任务）

| 岗位 | AI Agent应用场景 |
|------|-----------------|
| 运营 | Listing优化建议、促销策略推荐、补货数量智能计算 |
| 内容营销 | AI辅助文案创作、多语言Listing本地化、社媒内容生成 |
| 供应链 | 需求预测建模、供应商评分自动化、物流方案智能推荐 |
| 合规 | 商标/专利风险自动检测、合规文档到期提醒、法规变更推送 |
| 管理 | Dashboard自动生成、异常指标预警、OKR进度自动跟踪 |

### 4.3 中长期场景（需与业务系统深度集成）

| 场景 | 描述 |
|------|------|
| 端到端运营Agent | 从选品建议→Listing创建→广告投放→库存管理→客服的闭环AI运营 |
| 智能选品Agent | 基于大数据+AI的选品决策支持系统（市场→竞品→供应链→利润四维分析） |
| 全域广告优化Agent | 跨平台（Amazon + Google + Meta + TikTok）的整合广告智能优化 |
| 供应链智能Agent | 需求预测→自动补货→物流优化→风险预警的全链路智能供应链 |
