# Ozon 小预算实验：产品调研与选产品方法

> **平台专项参考，不是当前执行入口。** 仅当俄罗斯/Ozon 已通过跨市场选择并获 Owner 批准后，本文方法才适用；否则不得据此选择商品或启动采集。

> 研究日期：2026-07-11
> 历史假设：原适用对象为中国个人卖家、Ozon 首轮真实商品实验、总现金预算不超过 3,000 元；该金额来自未确认历史提案，当前不得自动采用。
> 重要说明：本文引用的平台规则和数据定义来自官方来源；“20→3→1”、预算分配、评分线及停止线是针对本实验设计的经营规则，不是 Ozon 官方承诺。平台费用、线路和合规要求会变化，花钱前必须用卖家后台和当期文件重新取证。

## 一、先说结论：产品调研不是“找爆款”，选产品不是“挑一个看起来会卖的东西”

**产品调研**是把一个模糊商品想法，逐步变成一组可验证事实：谁在 Ozon 搜、搜什么、现有商品怎样满足或没有满足、买家愿意付多少钱、中国能否稳定买到同规格商品、送到俄罗斯一件到底花多少钱、能否合法销售、最小批量失败时会损失多少。

**选产品**是基于这些事实作出资金决定：在多个线索中，只批准一个“需求存在、供给匹配、单位经济可行、合规可证明、损失可承受”的具体 SKU 做小批量真实验证。它不是选一个品类名称，而是选定完整组合：`目标买家需求 + 明确规格 + 供应商/批次 + 售价区间 + 履约线路 + 合规路径 + 试验数量`。

Ozon 官方将分析能力分为卖家分析、站点分析和“在 Ozon 卖什么”。其中趋势用于看买家更常搜索和下单的商品/类目；热门商品是最近 28 天在 Ozon 销售表现较好的商品；搜索查询是买家使用的热门查询；缺失商品是俄罗斯市场卖得好但 Ozon 尚未提供的商品。官方同时提供下单、加购、退货、活动效果、竞争位置等数据。这说明平台信号是研究入口，但任何单项都不是利润证明。[Ozon《分析工具》](https://docs.ozon.com/global/tr/analytics/analytics-and-metrics/analytics-tools/?country=TR)

## 二、把 Ozon 竞品、消费者需求与中国货源连成一条链

三者不是三张互不相关的表，而要通过同一个“需求—规格”对象连接：

`消费者搜索/抱怨的任务 → Ozon 上满足该任务的商品和价格 → 可生产同一关键规格的供应商 → 真实到岸成本与合规文件 → 可验证的商品方案`

### 1. 消费者需求：先记录“要解决什么”，不要先记录商品名

每条需求至少保存：俄语搜索词及中文含义、统计时间窗、搜索/浏览/加购/下单信号、目标价格带、常见使用场景、竞品评论中重复出现的优点和缺点。Ozon 的“我的商品查询”官方说明可看到带来浏览或购买的查询、搜索人数、看到商品的人数、平均搜索位置以及查询带来的订单收入；部分指标需要 Premium。搜索量代表注意，不等于购买意愿，查询收入和最终签收也仍不等于净利润。[Ozon Seller《新的商品查询分析》](https://seller.ozon.ru/media/news/novaya-analitika-po-zaprosam-tovarov/)

### 2. Ozon 竞品：比较的是同一需求下的替代方案

竞品不是“同类目所有商品”，而是买家在同一查询、价格带、规格和交付预期下会替换购买的商品。每个候选至少采集 5 个直接竞品（如不足则全部）：商品 ID/URL、卖家数、当前价与活动价、核心规格、评分与评论量、近期评价、交付时效、是否缺货、主图/标题承诺、差评问题。地区会影响商品是否可售，Ozon 消费者帮助也明确同一商品可能因城市和区域库存而不可用，因此必须固定俄罗斯收货城市和采集时间，不能把一次搜索页当作全俄供给。[Ozon《商品库存可用性》](https://docs.ozon.com/common/en/tovary/harakteristiki-i-nalichie/)

### 3. 供应商货源：按竞品的关键规格反向询价

把需求与竞品拆成可验收规格：材料、尺寸/重量、功能、耐用性、颜色/套装、包装、标签、缺陷容忍度。向至少 2 家独立供应商索取同一规格、同一数量阶梯和同一贸易条件的书面报价；必须含样品价、MOQ、阶梯单价、国内运费、包装、交期、重量尺寸、发票能力、质检/赔付条件、合规资料及有效期。链接或口头最低价不是成本证据；收到样品并按关键规格验收，才算“货源可匹配”。

### 4. 什么才叫“真实商品机会”

只有以下六类证据同时存在，才可进入 3 个候选；任一硬项缺失就是“待补证”，不是机会：

| 证据 | 最低可接受内容 | 不合格例子 |
|---|---|---|
| 需求 | Ozon 官方后台/公开页面的查询、趋势或真实成交相关信号；固定城市、时间窗和原始快照 | 第三方“潜力分”、短视频热度 |
| 竞争 | 同需求至少 5 个直接竞品的价格、规格、交付、评价问题；能说清差异点 | 只看销量榜第一名 |
| 货源 | 至少 2 份同规格书面报价，1 个可订样供应商，MOQ 在预算内 | 1688 展示价、不同规格比价 |
| 成本 | 当前线路的计费重/实重报价、平台费、汇兑与退货最坏情形；字段标记 actual/quoted/estimated/unknown | 只算采购价和头程 |
| 合规 | 明确 HS/ТН ВЭД 候选编码、Ozon 禁售核验、适用 EAEU 技术法规及所需证书/声明/标识；证据责任人明确 | “供应商说不用证” |
| 可验证性 | 小批量能在 3,000 元内运行，最坏不可回收损失不超过 1,200 元，并有预先写好的成败/停止标准 | 为拿低价一次买 100 件 |

## 三、20→3→1 漏斗

### 阶段 A：市场信号，形成 20 个“线索”

20 是探索宽度，不是 20 个采购对象。每条线索只需形成一页轻量证据：一个明确需求、一个规格方向、官方信号 URL/后台快照、3–5 个竞品、粗略售价带、主要未知项。去重按“同需求 + 同规格 + 同价格带”，换颜色或换供应商不能算新线索。

优先使用 Ozon 的趋势、热门商品、搜索查询、缺失商品等官方入口；热门商品的官方定义是最近 28 天表现较好的商品，因此它是滞后且可能已拥挤的信号，不应直接等同“值得进入”。[Ozon《分析工具》](https://docs.ozon.com/global/tr/analytics/analytics-and-metrics/analytics-tools/?country=TR)

硬淘汰：禁售/线路不收；合规类型无法确认；疑似侵权；易碎、带电、液体、粉末、食品、儿童/医疗等风险与本轮能力不匹配；预计售价覆盖不了保守成本；MOQ 使不可回收损失超过 1,200 元；无法获得两个供应来源。

### 阶段 B：供应商匹配，压到 3 个“可采购候选”

对通过硬筛的线索做同规格询价和样品验证。3 的含义是三套已经可以执行的商品方案，而不是三个“可能不错”的名字。每个候选应有：规格冻结版、两家报价、样品/质检结果、包装后的重量尺寸、当期运输报价、合规结论、保守利润表、风险和止损金额。

建议评分仅用于排序，不能覆盖硬门槛：需求证据 25%、竞争缺口 15%、货源匹配和质量 20%、保守单位经济 25%、合规与履约 15%。任何关键成本为 `unknown`、合规为未确认、样品未通过，均不得因总分高而入围。

### 阶段 C：到岸成本与合规复核，批准 1 个商品

“1”代表一次受控资金承诺：一个 SKU、一个主要供应商/批次、一条线路、一个批准售价与广告上限、一份现金预算、一套停止规则。不是永久主推品，更不是已经验证成功。

单件保守成本公式：

`采购 + 样品摊销 + 国内运费 + 包装/标签 + 出口申报/服务 + 跨境物流（按计费重） + 关税/税费 + Ozon 类目佣金 + 履约/处理费 + 广告与折扣 + 支付/提现/汇兑 + 退货/拒收/销毁期望损失 + 售后补偿`

Ozon 的中国线路按重量和货值分组，官方提供带生效日期的 XLSX 费率、时效和计算器，并提醒禁售商品承运商不会接收。故物流必须保存“线路、商品包装尺寸/重量、报价文件版本、生效日、采集日”，不可引用一张旧费率表长期计算。[Ozon《Ozon Partner Delivery》](https://docs.ozon.com/global/en/fulfillment/rfbs/logistic-settings/partner-delivery-ozon/)

平台佣金也必须以选定类目、卖家后台商品卡显示的佣金和当期结算规则为准；Ozon 官方卖家 App 帮助说明商品卡会展示佣金，且可录入成本和最低价格。最低价保护需要定期更新；过期后商品可能在全站活动中不再按该最低价处理，所以活动价不能假设等于日常售价。[Ozon《商品和价格管理》](https://docs.ozon.com/global/ozon-seller-app/product-management/) Ozon 也明确活动参与免费但折扣由卖家承担，活动可能改变曝光，因此“促销订单”不能证明原价需求。[Ozon《促销》](https://docs.ozon.com/global/promotion/promotions/promo/?country=OTHER)

### 阶段 D：小批量真实验证

建议预算不是“必须花完 3,000 元”，而是分阶段解锁：

- 账号、实时费用、收款、线路和合规未通过：采购预算 0 元；
- 调研/翻译/必要工具：0–200 元；
- 3 个候选样品、国内运费和测量：300–600 元；
- 1 个批准商品首批货与包装：600–1,000 元，数量以验证为准，不为 MOQ 扩量；
- 跨境履约预留：400–700 元；
- 广告/优惠测试：200–400 元，设置日限额；
- 退货、汇兑、补寄与意外准备金：至少 600 元。

任何时候累计**不可回收损失**达到 1,200 元，停止新增采购、广告和补货。其余预算仍是上限，不是继续下注的理由。

## 四、合规不是最后检查，而是进入 3 个候选前的硬门

EAEU 官方说明，联盟技术法规规定在联盟境内强制适用的产品安全要求；产品是否需要认证、符合性声明、国家注册、测试及 EAC 标志取决于具体商品和适用法规。[欧亚经济委员会《技术法规》](https://eec.eaeunion.org/en/comission/direction/texnreg/) 官方还维护统一强制符合性评估清单和进口时需提交符合性资料的制度文件，不能用“相似商品有人卖”替代法规判断。[EEC 技术法规文件目录](https://eec.eaeunion.org/en/comission/direction/texnreg/acts.php)

实际核验顺序：冻结商品材料/用途/电气参数/年龄段 → 取得候选 HS/ТН ВЭД 编码 → 查 Ozon 禁限售及承运限制 → 查适用 EAEU 技术法规和符合性形式 → 核实证书/声明的申请主体、型号覆盖、有效期与真伪 → 核对俄文标签、EAC、制造商/进口商信息 → 让承运/报关方书面确认可走当前线路。

中国出口端也要留档。海关官方规则要求跨境电商零售出口提交申报清单，并采用“清单核放、汇总申报/统计”；申报清单与报关单具有同等法律效力。[商务部转载海关总署 2018 年第 194 号公告](https://www.mofcom.gov.cn/zfxxgk/gkml/art/2021/art_1e97a9dbe17b45398e962927596b16f9.html) 海关办事指南列明合同、发票、运输单据、装箱单及许可证件等可能需要的单证，因此供应商能否提供真实品名、材质、货值、原产地和发票资料属于货源质量的一部分。[海关政务服务《进出口货物申报办事指南》](https://online.customs.gov.cn/static/pages/guides/000629002001/000629002001.html)

## 五、怎样判定成交、净利润与停止

### 1. 四个结果必须分开

1. **下单**：买家创建订单；可能取消、拒收或退款，不算成功。
2. **有效成交**：非 Owner、非亲友、非供应商的买家付款，商品真实发出并签收。
3. **最终有效成交**：签收后经过适用退货/争议观察期，无未决退款、退货、拒付或争议。
4. **最终净利润**：平台结算已完整，所有真实凭证入账，并扣除本文成本公式的全部项目；估算、待结算和未知费用存在时，只能叫“预计利润”。

Ozon 官方分析报告把已交付、已取消和已退回商品的应计及佣金分开，也提供退货和买家购买率等报告，支持上述区分；订单数不能替代交付、退回和结算事实。[Ozon《分析工具》](https://docs.ozon.com/global/tr/analytics/analytics-and-metrics/analytics-tools/?country=TR)

建议分别计算：

- `单件贡献利润 = 实收销售收入 − 该件全部变动成本`；
- `实验最终净利润 = 全部最终有效成交收入 − 全部直接/间接实验成本 − 退货争议等晚到调整`；
- 样品、失败批次、广告和销毁不能藏到“以后摊销”，首轮都计入本实验。

### 2. 预先写下停止、修正与加码条件

以下是小预算实验建议，不是 Ozon 官方阈值：

**立即停止**：账号/收款/类目/线路任一硬闸失败；合规文件无法验证；样品关键规格不合格且供应商不解决；当前售价下保守单件贡献利润不为正；累计不可回收损失 ≥1,200 元；出现侵权、安全或监管风险；关键成本仍为 unknown 却要求花钱。

**暂停并修正一次**：有合格曝光但点击弱（主图/定位问题）；点击/加购存在但不下单（价格、信任或交付问题）；订单出现但取消/拒收偏高（时效或描述问题）。每次只改一个主要变量，设新增损失上限；不能用不断降价和加广告掩盖商品问题。

**换品**：达到预设最小有效流量或测试期后，仍无独立真实买家的有效成交；或成交依赖低于可盈利价；或重复差评指向商品固有缺陷。最小流量/测试期必须发布前按可取得的后台指标写入实验，不能看到结果后改标准。

**小幅加码**：至少出现独立真实买家的最终有效成交；按真实结算计算的单件贡献利润为正；退货/争议无异常；第二批仍能以已验证质量和到岸成本供应。一次补货只覆盖下一验证周期，禁止因一单就放大采购。

### 3. 常见假信号

- 搜索量高：可能只是泛词、季节峰值或资讯需求；必须看具体查询到点击/订单的转化。
- 热门榜/高销量：代表过去 28 天表现或强广告/促销，也可能意味着竞争已拥挤。
- 评论多、评分高：是累计历史，不代表近期需求或新卖家能获得同样曝光。
- 搜索结果少：可能是需求小、地区不可售、类目词错误、合规/物流太难，不自动等于蓝海。
- 竞品高价：可能因品牌、俄罗斯本地库存、交付速度或售后溢价，不能直接套到无品牌跨境货。
- 1688 最低展示价：可能对应不同规格、超大 MOQ、未含税运或低质量批次。
- 毛利率高：漏掉佣金、活动折扣、计费重、汇兑、广告、拒收退货和销毁后会变成亏损。
- 加购、下单、付款：均可能在签收/退货/争议前逆转。
- 自买、亲友单、供应商单：不能证明独立需求，必须排除。
- 促销/广告单：只证明某个补贴价格和流量组合可成交；应单独记录自然与付费来源。

## 六、每个候选应保存的最小证据包

每个字段保存：来源 URL/API、原始 payload 或页面快照、采集城市、采集时间、采集方式、解析版本、`actual/quoted/estimated/unknown` 状态、有效期和冲突状态。最小清单为：

1. 需求：俄语查询、官方指标定义、时间窗、城市、趋势/查询原始证据；
2. 竞品：直接竞品清单、价格/活动/规格/交付/评论快照；
3. 货源：两份可比报价、样品订单、实测重量尺寸、验收结果、供应商主体；
4. 费用：类目佣金后台截图、当期线路 XLSX/计算器结果、广告与活动条件、汇兑/提现凭证；
5. 合规：商品归类依据、禁限售检查、适用法规、证书/声明/标签、承运书面确认；
6. 实验：批准人和时间、数量、预算、售价、广告上限、停止线、订单—物流—退货—结算关联；
7. 结果：有效成交、最终有效成交、最终净利润及全部晚到调整。

## 七、来源边界与待后台实证项

公开官方帮助能确认“有哪些数据与工具、物流如何分组、需要查禁售与动态费率、合规制度存在”，但无法替代中国卖家账户里的实时类目佣金、可用线路、收款方式、具体商品禁限售、活动状态和结算明细。首轮采购前必须在已验证账户中完成 48 小时实证闸门：账户可用、收款可闭环、选定类目可发布、当前佣金可读取、中国线路可承运、费用可计算、订单与结算可归因。任何硬项失败，采购预算保持 0 元。
