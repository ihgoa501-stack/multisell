### 外部写操作安全

> 所有 publish / approve / execute / price / inventory / refund 操作

| # | 打开页面 | 输入内容 | 观察点 | 预期结果 |
|---|----------|----------|--------|----------|

### 高风险确认弹窗

> 所有 publish / approve / execute / price / inventory / refund 操作

| # | 打开页面 | 输入内容 | 观察点 | 预期结果 |
|---|----------|----------|--------|----------|
| 1 | 任意高风险操作 | 触发操作 | 弹窗内容 | 弹窗显示：目标对象名称、风险等级（用颜色标识）、变更前后值对比、审计去向说明 |

## 如何使用本模板

1. 每个 Feature PR 合入时，开发者在 PR 描述中按本模板格式填写验收项
2. Owner 按验收项逐条测试，在"实测结果"列标记 ✅ 或 ❌
3. 所有验收项通过后才能标记该 Feature 为完成
4. 验收过程截图保存到 `docs/acceptance/` 目录
