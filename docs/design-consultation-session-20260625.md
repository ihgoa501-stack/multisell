## 最终设计系统决策

| 项目 | 决策 |
|------|------|
| **产品定位** | 跨境电商 AI Agent 工作台 |
| **审美方向** | AI Agent 桌面端 — 对话即操作，工具面板展开 |
| **装饰层级** | 极简 — 排版和间距承载视觉，颜色只在 AI 区域出现 |
| **主色** | Indigo `#6366F1` |
| **AI 色** | Cyan `#22D3EE` |
| **底色** | 暖黑 `#0B0B0E` → `#1A1A1E` → `#22222A`，5 阶层次 |
| **标题字体** | Cabinet Grotesk 800/600 |
| **正文字体** | DM Sans 400/500/600 |
| **代码字体** | JetBrains Mono |
| **间距** | 8px base，舒适密度 |
| **圆角** | xs(4px) → sm(6px) → md(8px) → lg(12px) |
| **动效** | 弹性曲线 0.4s cubic-bezier(0.22,1,0.36,1) |
| **明暗** | 暗色优先，亮色支持，`prefers-color-scheme` 自动适配 |
| **布局** | 三栏可调比例：Agent Hub(200px) ↔ 对话区 ↔ 工具面板 |
| **设计风险** | 跨境电商 SaaS 品类首个 AI-native 暗色界面 |
