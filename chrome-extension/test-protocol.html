凌镜 Extension — WebSocket 协议验证工具

该页面验证 extension 与后端之间的消息格式和协议流程。所有消息均为标准 JSON 格式。

协议概览

● WebSocket 连接流程 扩展 后端 │ │ ├── connect ───────────────→│ │ │ ├── {"type":"auth", │ │ "token":"..."} ───────→│ ← 连接后立即发送 Token │ │ │←─ {"type":"auth_ok"} ─────┤ ← 认证成功 │ │ │←─ {"type":"pong"} ────────┤ ← 每隔 15s 心跳回复 │ │ ● Fetch Product 请求/响应流程 后端 扩展 Background Content Script │ │ │ ├─ fetch_product ─→┤ │ ← WS 消息 │ ├─ tab.sendMessage ─→┤ │ │ ├─ 提取页面数据 │ │←── sendResponse ───┤ │←─ fetch_product_result ─┤ │ ← WS 消息 │ │ │

消息格式规范

1. 认证消息 REQUIRED

Extension → Server 
{
  "type": "auth",
  "token": "eyJhbGciOiJIUzI1NiIs..."
}
连接建立后立即发送。使用 JWT Bearer Token。

2. Heartbeat REQUIRED

Extension → Server 
{
  "type": "ping"
}
Server → Extension 
{
  "type": "pong"
}
每隔 15 秒发送 ping。

3. Fetch Product 请求

Server → Extension 
{
  "type": "fetch_product",
  "id": "req_uuid",
  "payload": {
    "url": "https://detail.1688.com/offer/123.html"
  }
}

4. Fetch Product 成功响应

Extension → Server 
{
  "type": "fetch_product_result",
  "id": "req_uuid",
  "payload": {
    "status": "ok",
    "data": { ... }
  }
}

5. Fetch Product 错误响应

Extension → Server 
{
  "type": "fetch_product_error",
  "id": "req_uuid",
  "payload": {
    "code": "TAB_NOT_FOUND",
    "message": "No open tab found for URL: ..."
  }
}

6. Content Script 内部消息

Background → Content Script 
{
  "type": "fetch_product_from_page",
  "requestId": "req_uuid"
}
Content Script → Background 
{
  "type": "fetch_product_from_page_result",
  "requestId": "req_uuid",
  "payload": {
    "status": "ok",
    "data": {
      "source_url": "...",
      "collected_at": "2026-06-26T...",
      "driver": "extension",
      "title": "商品标题",
      "price_1688": 29.99,
      "price_min": 19.99,
      "price_max": 39.99,
      "currency": "CNY",
      "min_order_qty": 2,
      "images": [
        "https://cbu01.alicdn.com/...jpg"
      ],
      "spec_variants": [
        { "spec": "红色/L", "price": 29.99, "stock": 100 }
      ],
      "supplier_name": "某某工厂",
      "supplier_id_1688": "12345678",
      "description": "商品描述..."
    }
  }
}

PageData Schema

字段 类型 必需 说明
source_url string 是 商品页面 URL
collected_at string 是 ISO 8601 采集时间
driver string 是 固定值 "extension"
title string 是 商品标题
price_1688 number 是 1688 价格 (CNY)
price_min number|null 否 规格最低价
price_max number|null 否 规格最高价
currency string 是 固定值 "CNY"
min_order_qty number 是 最小起订量 (默认 1)
images string[] 否 商品图片 URL 列表
spec_variants array 否 SKU 规格列表
supplier_name string 否 供应商名称
supplier_id_1688 string 否 供应商 1688 ID
description string 否 商品描述摘要
