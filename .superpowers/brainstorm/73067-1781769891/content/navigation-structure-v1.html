页面分组

AgentOS 总控台：新增主页面，聚合当前 `dashboard/Dashboard.vue` 和 `agent/Dashboard.vue` 的价值，但以任务和审批为中心。

任务中心：新增统一列表，把现有 `AgentActions`、`ExceptionWorkbench`、`NotificationCenter`、待确认决策整合为同一种“工作项”。

Agent 小队：重组现有 `AgentList`、`AgentDetail`、`AgentRules`、`EntropyCockpit`，按增长/履约/风控展示，而不是按 A1-A7 平铺。

模板与技能：第一版不是开放画布，而是展示跨境电商内置模板：上架决策、Listing 优化、库存补货、利润风控、客服草稿。

业务数据：当前商品、库存、订单、物流、结算、平台、财务页面继续保留，但定位变成 Agent 的上下文数据层。

审计与安全：把操作日志、RBAC、熵管理、安全红线、AI 审计统一起来，作为差异化卖点。

这样重组的好处

  • 用户第一眼看到的是 AI 工作台，不是传统后台。
  • 现有业务页面不用推倒重写。
  • Agent、异常、审批、通知统一成任务语义。
  • 审计与安全被提升为产品能力。

需要避免

  • 不要在左侧导航暴露 30 个平级模块。
  • 不要把 Agent 小队做成纯展示卡片。
  • 不要让模板变成复杂低代码画布。
  • 不要把安全审计藏在系统设置里。
