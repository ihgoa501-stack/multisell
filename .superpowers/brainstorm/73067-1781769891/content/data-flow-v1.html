统一 WorkItem 概念

第一版不一定要立刻新增一张大表，但前端和产品语义必须有统一的 WorkItem 工作项：它可以来自 AgentAction、ExceptionItem、Notification、AgentDecision。用户在任务中心看到的是统一任务，而不是四种技术对象。

每个 WorkItem 至少包含：来源模块、业务对象、Agent/小队、风险等级、建议动作、状态、审批要求、审计链接。

必须统一的规则

  • 所有 Agent 输出都要落到决策日志。
  • 所有可执行动作都要经过风险判定。
  • 高风险动作必须进入审批队列。
  • 所有执行结果都要写操作日志。
  • 用户反馈要反哺信任评分和自治等级。

第一版先不强求

  • 不要求所有业务事件实时流式触发。
  • 不要求所有 Agent 都能自动写回平台。
  • 不要求复杂 DAG 可视化编辑。
  • 不要求 IM 双向审批闭环。
