## 一、运营专员 / 运营经理

### 1.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 9:00-12:00 | 查看店铺销量与销售额；处理买家消息（24h 内回复）；检查账号健康状态；查看平台官方通知 |
| 下午 12:00-17:00 | 广告优化（CPC 出价、否定词、关键词结构）；数据分析（流量、转化率、ACoS）；Listing 检查与微调；库存监控（IPI、可售天数） |
| 傍晚 17:00-21:00 | 竞品监控（价格、促销、上新）；中差评处理；跟卖检查；新品工作（选品调研、Listing 撰写、发货计划） |

### 1.2 核心决策点

| 决策类型 | 判断内容 | 数据依据 |
|---------|---------|---------|
| 选品决策 | 上什么新品、是否跟进爆款 | 市场容量、竞品销量、Google Trends、社媒讨论增长率、供应链匹配度 |
| 定价策略 | 售价调整、促销折扣力度 | 竞品价格、利润率、广告成本、物流费用、汇率波动 |
| 广告投放 | 预算分配、关键词出价、否定词 | ACoS、CTR、转化率、广告 ROI |
| 库存决策 | 补货量、清仓、断货预警 | 库存周转率、IPI 分数、销售速度、物流周期、库龄 |
| Listing 优化 | 标题/关键词/图片调整 | 搜索排名变化、流量来源、转化率、跳出率 |

### 1.3 常用工具链

- **ERP**：店小秘、积加 ERP、易仓 ERP、领星 ERP、马帮 ERP、赛盒 ERP、通途 ERP
- **选品与数据分析**：Jungle Scout、卖家精灵、Helium 10、Keepa、Google Trends
- **广告与流量**：亚马逊 CPC 广告后台、AdSpy、TikTok Ads Manager
- **BI 与财务**：数跨境 BI、Tableau、FineBI、万里汇/派安盈/连连支付
- **安全与效率**：紫鸟浏览器/飞跨浏览器、影刀 RPA

### 1.4 关键 KPI

| 类别 | 指标 |
|------|------|
| 销售业绩 | GMV、订单量、客单价、利润率、渠道贡献率 |
| 运营效率 | 广告 ROI、库存周转率、物流时效、退款率/纠纷率 |
| 客户服务 | 24h 回复率、CSAT（≥4.5）、差评率（≤0.5%）、退货率 |
| 市场拓展 | 新品推广成功率（≥30%）、竞品分析报告频率 |

### 1.5 典型痛点

- 政策与关税不确定性（欧盟取消 150 欧元以下免税、美国加征关税）
- 平台合规风险（亚马逊封号潮）
- 广告成本上升，ACoS 难以控制
- 库存管理两难（断货影响排名，压货占用资金）
- 同质化竞争严重，低价内卷
- 多平台数据分散，利润核算需跨数十张表

### 1.6 协作关系

- **产品开发/选品**：提供市场数据与需求洞察
- **采购/供应链**：提供销量预测和补货计划
- **物流/仓储**：监控库存水位和 IPI
- **客服**：制定 FAQ 和售后话术
- **设计/美工**：提供 Listing 优化需求
- **推广/广告投放**：统筹广告策略
- **财务**：提供销售台账，核算多平台利润

## 二、选品专员 / 产品开发 / 采购

### 2.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 9:00-12:00 | 数据复盘（销售/库存/竞品动态）；市场调研（热销榜、Google Trends、社媒热点）；选品初筛 |
| 下午 13:00-18:00 | 供应商对接（1688/阿里国际站询价谈判）；样品跟进；产品评估（利润测算、侵权排查、合规审核）；跨部门沟通 |
| 晚间 18:00+ | 跟进海外时差邮件；更新选品数据库；复盘已上架产品销售表现 |

### 2.2 核心决策点

**选品决策五大维度**：
1. 市场需求验证（搜索趋势持续性、社媒热度、平台销量曲线）
2. 竞争格局分析（头部卖家集中度、评论数量门槛、同质化程度）
3. 利润空间测算（净利润 = 售价 - 采购成本 - 物流成本 - 平台费用 - 广告费用 - 售后成本）
4. 供应链匹配度（工厂产能、交期稳定性、小批量试单支持度）
5. 合规风险评估（目标市场认证要求、知识产权、平台政策限制）

**典型决策流程**：粗选 → 产品验证（推广难度/竞争度/差评分析）→ 数据实测（小批量试单）→ 侵权查询 → 功能实测 → 供应商谈判 → 批量采购

### 2.3 常用工具链

- **选品分析**：Jungle Scout、Helium 10、卖家精灵、Keepa、Google Trends、知虾数据
- **供应链平台**：1688、阿里巴巴国际站、义乌购、AliExpress Dropshipping Center
- **社媒爆款追踪**：TikTok Trends、Minea
- **办公与 ERP**：Excel（数据透视）、ERP 系统（芒果店长、店小秘）、ChatGPT

### 2.4 关键 KPI

| 类别 | 指标 |
|------|------|
| 结果指标 | 新品开发成功率、销售额/毛利额达成率、库存周转率 |
| 过程指标 | 产品上架数/开发周期 |
| 质量指标 | 退货率、账号健康度/风控 |
| 成本指标 | 广告费占比（控制在健康水平） |
| 采购专属 | 采购成本降低率、供应商交货准时率、质量合格率、库存周转天数 |

### 2.5 典型痛点

- 信息过载与判断延迟，伪需求陷阱（短期热卖跟进后窗口期已过）
- 利润幻觉（表面毛利好看，扣除各项成本后实际亏损）
- 来货时间不确定，质量波动带来退货、差评、账户风险
- 库存积压与断货并存
- 知识产权侵权、认证门槛、平台政策多变
- KPI 扭曲（销量导向导致大量上架低质量产品）

### 2.6 协作关系

- **运营团队**：提供市场反馈与销售数据；接收选品方案与产品卖点
- **采购/供应链**：供应商开发、价格谈判、交期管理
- **仓储/物流**：库存监控、补货计划、到货安排
- **质检团队**：样品测试、质量标准确认
- **财务**：预算制定、成本核算、付款审批
- **设计/美工**：产品图片、Listing 素材制作

## 三、客服专员 / 售后专员

### 3.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上班前/早晨 | 查看夜间积压邮件/站内信/工单，优先处理紧急纠纷和 A-to-Z 申诉 |
| 上午 | 回复各平台客户咨询；处理订单查询、物流跟踪；审核退换货申请 |
| 中午 | 跟进物流异常订单；处理差评预警和投诉升级 |
| 下午 | 处理复杂售后纠纷（质量争议、物流丢失索赔）；整理客户反馈数据；跨部门沟通会议 |
| 傍晚 | 完成当日工单闭环，更新 CRM/工单系统；撰写工作日志和问题汇总报告 |
| 夜间（轮班/外包） | 覆盖欧美时区，确保 24 小时响应 |

### 3.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 退换货审批 | 是否同意退货、退款金额、是否承担退货运费 |
| 纠纷判责 | 在平台纠纷中基于证据判定买卖双方责任 |
| 补偿方案 | 针对物流延迟或商品瑕疵，决定补偿力度（优惠券/退款/补发） |
| 差评应对 | 评估差评内容，决定是否联系客户修改或向平台申诉移除 |
| 升级处理 | 判断问题是否需升级至法务、物流或产品部门 |

### 3.3 常用工具链

- **工单系统**：Zendesk、Freshdesk、Gorgias、Intercom、Re:amaze
- **平台后台**：Amazon Seller Central、eBay 后台、Shopee/Lazada/TikTok Shop 卖家中心
- **翻译工具**：DeepL、Google Translate、AI 实时翻译插件
- **物流查询**：17TRACK、AfterShip、物流商 API
- **CRM**：Salesforce Service Cloud、HubSpot
- **社交通讯**：WhatsApp、Messenger、Instagram DM、Line

### 3.4 关键 KPI

| 指标 | 行业基准 |
|------|---------|
| 首次响应时间(FRT) | Chat ≤60 秒，邮件 ≤4 小时 |
| 平均处理时间(AHT) | 标品 3-5 分钟，复杂品 6-9 分钟 |
| 一次性解决率(FCR) | ≥80%-88% |
| 客户满意度(CSAT) | ≥4.2-4.5/5 |
| 24h 回复率 | ≥95%-98% |
| ODR（订单缺陷率） | ≤1% |
| A-to-Z 申诉胜诉率 | ≥65%-80% |
| 重复投诉率 | ≤3% |

### 3.5 典型痛点

- 时差问题（欧美客户活跃时间与中国团队重叠少）
- 多语言沟通（翻译耗时易出错，小语种人才稀缺）
- 多平台数据孤岛（需反复切换多个系统查证信息）
- 物流不可控（47% 跨境订单纠纷源于物流信息不透明）
- 平台规则复杂（Amazon A-to-Z、Temu 90 天退货、欧盟 14 天无理由退货）
- 差评压力大（一个差评可导致转化率下降约 1%）
- 情绪劳动强度高

### 3.6 协作关系

- **运营**：同步促销活动、产品信息更新；反馈客户对 Listing 的疑问
- **物流/仓储**：协调发货延迟、包裹丢失、库存不足等问题
- **采购**：反馈产品质量问题；推动供应商改进
- **产品/技术**：传递客户对产品功能、使用方法的反馈
- **财务**：处理退款审批、赔偿核算
- **法务**：处理知识产权投诉、合规纠纷

## 四、物流专员 / 仓储管理 / 供应链专员

### 4.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 早晨 | 查看系统待处理订单；确认昨日发货状态；检查物流异常预警 |
| 上午 | 处理新订单物流方案匹配（空运/海运/专线/海外仓）；制作/审核报关资料；安排当日出库计划 |
| 中午 | 跟进在途货物状态；处理海关查验、清关延误等异常；与货代/物流商对接 |
| 下午 | 入库验收（核对 SKU、数量、质检）；库位规划与调整；拣货/打包/贴标作业监督 |
| 傍晚 | 生成出库单，与物流公司交接；更新 WMS/ERP 系统库存数据；核对当日出入库记录 |
| 定期工作 | 库存盘点（月度循环盘点+季度全盘）；物流商 KPI 评估；补货计划制定 |

### 4.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 物流渠道选择 | 根据商品属性（重量/体积/货值）、时效要求、成本预算选择最优运输方式 |
| 库存补货策略 | 基于销售预测和库存周转率，决定补货数量和时机 |
| 海外仓备货 | 判断哪些 SKU 适合海外仓前置，平衡库存持有成本与履约时效 |
| 异常处理方案 | 面对清关延误、包裹丢失、破损等情况，决定赔偿/补发/退款方案 |
| 供应商切换 | 当主用物流商出现持续时效问题时，是否切换至备选供应商 |

### 4.3 常用工具链

- **ERP**：店小秘、马帮、聚水潭、吉客云
- **WMS**：四方网络 WMS、跨境易 WMS、谷仓海外仓系统、大健云仓
- **物流跟踪**：17TRACK、AfterShip、物流商 API
- **报关系统**：单一窗口、四方网络 9810 报关系统
- **数据分析**：Excel、BI 工具、物流数据看板
- **硬件**：PDA 扫描枪、RFID 读写器

### 4.4 关键 KPI

| 类别 | 指标 | 行业基准 |
|------|------|---------|
| 效率指标 | 订单处理时效、拣货速度、发货准时率 | 24h 内发货率 ≥95% |
| 准确率指标 | 拣货准确率、库存准确率、面单匹配率 | ≥99% |
| 库存管理 | 库存周转率、呆滞库存占比、盘点差异率 | 周转天数 <60 天 |
| 成本指标 | 单位订单处理成本、人均处理订单数、储运费用控制率 | 控制在预算 100% 以内 |
| 服务指标 | 退货处理时效、客户投诉率、理赔处理时效 | 投诉率 ≤2% |
| 安全指标 | 货物完好率、仓库安全事故率 | 零事故目标 |

### 4.5 典型痛点

- 清关不确定性（"清关慢一天，利润少一半"，滞港费每个柜子 150-200 美元/天）
- 库存积压与断货两难
- 海外仓成本压力（租金约占海外仓成本 60%，2023 年美国仓库租金增长 12%）
- 爆仓与产能瓶颈（旺季订单激增，仓库爆仓、物流运力紧张）
- 逆向物流成本高（跨境退货运费常接近或超过产品货值）
- 多仓多平台管理复杂（不同国家法规、标签、配送要求）
- 信息不透明（物流轨迹更新滞后）

### 4.6 协作关系

- **运营**：同步促销计划，提前备货；反馈库存状态，避免超卖
- **采购**：协调供应商交货时间、质检标准；处理来料异常
- **客服**：提供物流轨迹信息；协同处理物流延迟/丢失投诉
- **财务**：核算物流成本、关税、VAT；处理物流商付款
- **销售/市场**：根据物流能力评估新市场拓展可行性
- **技术/产品**：对接 WMS/ERP 系统；优化自动化流程

## 五、市场推广 / 广告投放专员

### 5.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 9:00-12:00 | 查看前一日各渠道广告数据（Facebook/Google/TikTok），分析 CTR、CPC、ROAS；检查预算消耗进度；回复红人邮件；审核红人素材 |
| 下午 13:00-18:00 | 制作/优化广告创意素材；搭建新广告系列；筛选新红人资源；与运营团队同步投放效果 |
| 晚间（视目标市场时区） | 监控美国/欧洲市场黄金时段投放效果；处理紧急账户问题（如 Facebook 广告账户被封） |

### 5.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 渠道选择 | 时尚快消类优先 TikTok/Instagram，高客单家居类侧重 Facebook/Google Shopping |
| 出价策略 | 新品期采用"最大化转化量"（预算为预估日均销售额的 8%-12%），成熟期切换至 tROAS 模式 |
| 红人筛选 | 优先看互动率而非粉丝数，核查数据真实性、合作历史 |
| 预算分配 | 排除已转化 7 天内用户、低质量流量池，排除比例建议不低于 15% |

### 5.3 常用工具链

- **广告投放**：Meta Business Suite、Google Ads、TikTok Ads Manager
- **红人营销**：Socialbakers、Upfluence、Noxinfluencer
- **数据分析**：积加 ERP 广告看板、达麦 ERP、Google Analytics
- **素材制作**：Canva、CapCut、Photoshop
- **协同管理**：UTM 参数追踪、飞书/钉钉

### 5.4 关键 KPI

| 类别 | 指标 |
|------|------|
| 效果指标 | ROAS、ACoS、CPA、CPC、CTR |
| 红人营销指标 | 观看率、互动率、CPE、CPV、品牌活力指数(VIT) |
| 销售指标 | 引流转化率、独立站销售额、新品推广达标率 |
| 运营指标 | 广告账户健康度、素材更新频率、红人合作履约率 |

### 5.5 典型痛点

- 账户风险（Facebook/Google 广告账户频繁被封）
- ROI 难衡量（超过 30% 营销人员不清楚网红营销 ROI）
- 时差问题（需配合目标市场时区工作）
- 素材疲劳（广告创意生命周期短，需持续产出本地化内容）
- 红人合作风险（数据造假、内容风格不匹配、交付延期）

### 5.6 协作关系

- **运营团队**：同步库存情况，避免过度营销导致断货或库存积压
- **数据分析师**：获取投放效果深度分析，优化人群定向
- **设计团队**：协同制作本地化创意素材
- **财务**：核对广告费用支出、ROI 核算

## 六、数据分析师 / BI 专员

### 6.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 9:00-12:00 | 导出前一日各平台销售报表、广告数据、订单记录；核对 ERP 库存与平台库存差异；制作日销售库存表；监控异常数据 |
| 下午 13:00-18:00 | 需求确认（与业务部门对齐分析目标、数据口径）；数据处理（清洗脏数据）；专题分析（选品/竞品/广告 ROI/库存周转）；可视化报表更新 |
| 周期性工作 | 周度：竞品价格监控、广告渠道效果复盘、库存周转率分析；月度：财务报表编制、预算差异分析；季度：市场趋势预测、年度预算预测 |

### 6.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 选品决策 | 通过排行榜单分析、市场需求分析指导选品 |
| 库存预警 | 根据历史销量、季节性趋势预测备货需求 |
| 广告优化 | 识别高效 ROI 推广途径，实时调整投放策略 |
| 定价策略 | 结合汇率波动、物流成本、平台佣金测算产品盈利能力 |

### 6.3 常用工具链

- **数据库/取数**：SQL、Python/Pandas、平台 API 接口
- **可视化/BI**：Power BI、Tableau、FineBI、数跨境 BI
- **分析模型**：RFM 模型、波士顿矩阵、线性回归预测
- **外部数据**：Jungle Scout、Google Trends、Statista、SimilarWeb
- **系统对接**：ERP（领星、店小秘）、OMS、WMS

### 6.4 关键 KPI

| 类别 | 指标 |
|------|------|
| 分析效率 | 报表准时提交率、数据准确率 |
| 业务支持 | 需求响应速度、分析结论被采纳率 |
| 预测准确度 | 销量预测偏差率、库存预警准确率 |
| 成本优化 | 通过数据分析实现的库存成本降低、广告 ROI 提升幅度 |

### 6.5 典型痛点

- 数据分散（前端多平台，后端多系统）
- 数据质量差（商品分类字段不统一、广告转化定义不同、时区混乱）
- "救火式"分析（业务节奏快，需求多且紧急，难以做深度分析）
- 跨时区分析（需按站点当地时间统一）
- 外部数据验证难（第三方报告可能夸大市场增长率）

### 6.6 协作关系

- **运营团队**：提供销量/广告/库存分析支持
- **市场推广**：提供广告渠道效果分析、人群画像分析
- **供应链/采购**：提供库存周转分析、备货预测、多仓补货策略
- **财务**：提供利润分析、成本分析、费用分析数据支持
- **管理层**：输出可视化驾驶舱，支持战略决策

## 七、跨境电商财务 / 会计

### 7.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 月初 1-5 日 | 导出各平台月度结算报表；核对订单收入、平台费用、退款/退货数据；获取头程/尾程物流账单；核对第三方支付流水 |
| 月中 6-20 日 | 按权责发生制确认收入；核对供应商采购发票；计算并申报目标国 VAT；处理进口关税与退税；监控多币种账户余额，规划外汇兑换时机 |
| 月末 21-31 日 | 编制多币种合并利润表、资产负债表、现金流量表；按平台/国家/产品线拆分收入与成本；计提应付未付费用、调整汇兑损益；对比预算与实际数据 |
| 专项工作 | 出口退税申报；税务核查配合 |

### 7.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 收入确认时点 | 按发货还是按结算确认 |
| 汇率折算规则 | 按交易日汇率还是月末汇率 |
| 外汇兑换时机 | 基于汇率波动预测，选择最优结汇时点 |
| 退税模式选择 | 9610（清单合放）vs 9810（海外仓）vs 一般贸易回流 |
| 库存减值计提 | 滞销库存是否计提减值、计提比例 |

### 7.3 常用工具链

- **ERP**：领星、店小秘、马帮
- **财务软件**：金蝶、用友、QuickBooks、Xero
- **税务申报**：电子税务局、单一窗口、跨国通报关系统
- **支付对账**：PayPal、Stripe、连连支付、PingPong
- **汇率工具**：银行外汇牌价、XE Currency、Bloomberg

### 7.4 关键 KPI

| 类别 | 指标 |
|------|------|
| 核算准确性 | 报表差错率、对账差异率 |
| 合规性 | 税务申报及时率、退税申报准确率 |
| 资金周转 | 退税周期、应收账款周转天数 |
| 成本控制 | 汇兑损益控制、手续费占比 |
| 报表时效 | 月结关闭天数、管理报表输出及时性 |

### 7.5 典型痛点

- 外汇匹配难（零散收汇难以与报关单逐一对应）
- 收汇金额差异（平台提前扣除各项费用，实际到账金额低于报关金额）
- 出口退税流程复杂（9610/9810 模式政策不明确，不同地区执行标准不一）
- 汇率波动风险（多币种结算导致汇兑损益波动大）
- 主体混乱问题（店铺挂靠在亲戚名下、公司地址异常）
- ERP 系统不成熟（不同平台数据不打通，财务核算需跨数十张表）

### 7.6 协作关系

- **运营团队**：获取平台结算数据、核对订单退款/退货
- **供应链/物流**：核对头程/尾程物流账单、海外仓费用
- **数据分析师**：获取销售/库存数据支持利润核算
- **采购**：核对供应商发票、安排付款
- **管理层**：输出财务报表、预算差异分析、资金规划建议

## 八、店长 / 店铺负责人

### 8.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 | 查看店铺销量和销售额；回复买家信息；广告数据检查 |
| 下午 | 数据分析（流量/销售/广告）；中差评处理；库存监控 |
| 晚间 | 竞品监控（筛选 20 家相似度 80% 以上 Top 竞品）；新品工作 |

### 8.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 备货策略 | 采用"30-60-90 原则"：FBA 仓保持 30 天库存、在途 30 天库存、供应商备用 30 天库存 |
| 定价策略 | 结合竞品价格、平台佣金、物流成本、广告成本、目标利润率综合定价 |
| 广告投放 | 决定每日广告预算分配、关键词出价、否定关键词设置 |
| Listing 调整 | 销量稳定后不轻易调整 Listing（影响权重），仅在数据严重错误时微调 |

### 8.3 常用工具链

- **平台后台**：亚马逊卖家中心、TikTok Shop 后台、Shopee 卖家中心
- **ERP**：店小秘、领星 ERP、芒果店长
- **选品工具**：卖家精灵、Jungle Scout、Keepa、Google Trends
- **广告优化**：Helium 10、优麦云
- **数据分析**：数跨境 BI、卖家网
- **AI 工具**：Kua.ai、ChatGPT
- **防关联**：紫鸟浏览器、飞跨浏览器

### 8.4 关键 KPI

- 销售额/GMV（月度/季度销售目标达成率）
- 利润率（扣除平台佣金、广告费、物流费后的净利润）
- 广告 ACoS（通常目标控制在 15%-30%）
- 库存周转率（入仓库存需在 3 个月内卖完）
- 库存绩效指数（IPI，亚马逊要求不低于 500）
- Review 评分（维持 4 星以上）
- 订单缺陷率（ODR，低于 1%）
- 消息回复时效（24 小时内回复率 100%）

### 8.5 典型痛点

- 断货与库存积压的两难
- 平台政策多变，封号风险
- 广告成本攀升，ACoS 容易失控
- 竞品恶意攻击（跟卖、恶意差评、投诉）
- 多店铺管理复杂（账号关联风险、数据分散）

### 8.6 协作关系

- **供应链/物流经理**：提供销售预测和备货需求
- **选品/产品专员**：反馈市场数据和用户 Review
- **客服专员**：移交中差评处理、异常订单跟进
- **市场推广专员**：协调站外引流、红人合作、促销活动
- **财务**：核对利润数据、广告费用、回款情况

## 九、供应链经理 / 物流经理

### 9.1 日常工作流

| 时间段 | 核心任务 |
|--------|---------|
| 上午 | 库存数据盘点（各仓库库存量、在途货物状态）；订单履约监控；物流商对接 |
| 下午 | 采购计划审核；物流方案评估；异常处理（丢件、破损、延误、清关扣货） |
| 定期工作 | 供应商绩效评估（OTIF、质量合格率）；物流成本分析；需求预测会议（S&OP） |

### 9.2 核心决策点

| 决策场景 | 判断内容 |
|---------|---------|
| 物流方式选择 | 新品测款用国际快递/空运；成长期用空运头程+FBA；成熟期用海运+FBA 为主+第三方仓备份 |
| 海外仓布局 | 决定是否使用 FBA、第三方海外仓或自营海外仓 |
| 安全库存设定 | 安全库存 = 日均销量 × 补货周期 + 缓冲量；补货点 = 日均销量 × 物流周期 + 安全库存 |
| 供应商选择 | 评估供应商交货能力、质量稳定性、价格竞争力 |

### 9.3 常用工具链

- **ERP**：积加 ERP、易仓 ERP、领星 ERP
- **WMS**：吉客云、各海外仓自有 WMS
- **TMS**：对接物流商的运输管理系统
- **物流查询**：17Track、AfterShip
- **物流服务商**：云途物流、递四方、燕文、4PX
- **海外仓服务商**：万邑通、谷仓、飞鸟、递一达

### 9.4 关键 KPI

- 订单履约时效（从下单到签收的完整周期）
- 库存周转率（"黄金法则"：库存增长低于 GMV 增长）
- 物流成本占比（物流费/GMV）
- 妥投率
- 缺货率/在架率（目标 98% 以上）
- 滞销库存占比（DOS>180 天定义为滞销）
- 单均物流成本
- 供应商 OTIF（准时足量交货率）
- 破损率/客户投诉率
- 清关时效

### 9.5 典型痛点

- 库存平衡难题（缺货导致销售损失，积压占用资金）
- 物流时效与成本矛盾（海运成本低但时效慢 25-40 天；空运快但成本是海运的 4-8 倍）
- 跨境不确定性多（港口拥堵、清关延误、航线停航、货代跑路）
- 多仓协同复杂（FBA+第三方仓+国内仓的多点库存管理）
- 旺季备货压力（黑五、圣诞等旺季需提前 2-3 个月备货）
- 合规风险（各国海关法规、税务政策、产品认证要求不同）

### 9.6 协作关系

- **运营/店长**：接收销售预测和备货需求，反馈库存状态
- **采购部门**：根据库存和销售数据制定采购计划
- **客服部门**：处理物流异常订单、退换货、客户投诉
- **财务部门**：核对物流费用、仓储费用、采购付款
- **法务/合规**：确保产品合规、清关文件齐全

- 招聘成本（人均招聘费用）
- 人才推荐成功率（Offer 率，行业平均 15%-25%）
- 员工满意度/敬业度
- 培训覆盖率

### 10.5 典型痛点

- 人才缺口巨大（2025 年跨境电商核心岗位人才缺口已近千万）
- 复合型人才稀缺（"外语+电商运营+数据分析+AI 工具"）
- 人才流动性极高（项目制用工常态）
- 薪资结构复杂（基础酬劳+销量提成+绩效奖励+跨境补贴）
- 税务合规风险（金税四期下，跨境收入申报、灵活用工性质界定）
- 行业知识壁垒深（HR 需理解跨境电商业务逻辑才能精准识别人才）

### 10.6 协作关系

- **运营/业务部门**：接收招聘需求，明确岗位能力要求
- **财务部门**：确认薪酬预算、处理复杂薪资核算、税务合规
- **法务/合规**：确保劳动合同、灵活用工协议、跨境用工合规
- **管理层/Boss**：汇报人才战略、组织架构优化建议、人力成本分析

| 推广 | 数据分析 | 获取投放效果深度分析 |
| 数据分析 | 运营 | 提供销量/广告/库存分析 |
| 数据分析 | 供应链 | 提供库存周转分析、备货预测 |
| 财务 | 运营 | 核对平台结算数据 |
| 财务 | 物流 | 核对物流账单 |
| HR | 运营 | 接收招聘需求 |
| HR | 财务 | 确认薪酬预算 |

## 十二、Agent 设计建议

### 12.1 单岗位 Agent 设计要点

| 岗位 | Agent 核心能力 | 建议输入 | 建议输出 |
|------|---------------|---------|---------|
| **运营专员** | 店铺监控、广告优化、竞品跟踪 | 平台后台数据、广告报表、库存数据 | 日报/异常预警、广告调整建议、竞品动态摘要 |
| **选品专员** | 市场洞察、利润测算、侵权筛查 | 热销榜单、供应商报价、竞品数据 | 选品评分卡、利润测算表、风险评估报告 |
| **客服专员** | 多语言回复、纠纷处理、情感分析 | 客户消息、订单数据、物流状态 | 标准回复话术、纠纷处理建议、客户满意度分析 |
| **物流专员** | 路径优化、库存预警、异常处理 | 订单数据、物流轨迹、库存数据 | 最优物流方案、补货预警、异常处理工单 |
| **推广专员** | 广告投放、红人筛选、素材优化 | 广告数据、红人数据库、竞品广告 | 出价策略、红人推荐名单、素材优化建议 |
| **数据分析师** | 数据清洗、可视化、预测模型 | 多平台原始数据、业务问题 | 清洗后数据集、BI 报表、预测结果 |
| **财务** | 对账、税务申报、汇率管理 | 平台结算单、物流账单、银行流水 | 对账差异报告、税务申报表、汇率风险预警 |

### 12.2 多 Agent 协作架构建议

```
┌─────────────────────────────────────────┐
│           调度/协调 Agent（店长级）          │
│    （任务分发、结果汇总、冲突仲裁）            │
└─────────────────────────────────────────┘
                    │
    ┌───────────────┼───────────────┐
    │               │               │
┌───┴───┐      ┌───┴───┐      ┌───┴───┐
│ 运营Agent │      │ 供应链Agent│      │ 客服Agent │
│ 推广Agent │      │ 物流Agent  │      │ 财务Agent │
│ 选品Agent │      │ 采购Agent  │      │ HR Agent  │
│ 数据Agent │      │ 仓储Agent  │      │           │
└───────┘      └───────┘      └───────┘
```

### 12.3 通用设计原则

1. **数据接口标准化**：每个 Agent 需统一对接 ERP、平台 API、WMS 等系统的数据格式
2. **时区感知**：跨境电商涉及多时区，Agent 需按目标市场当地时间执行任务
3. **多语言支持**：客服、推广 Agent 需支持多语言输入输出
4. **异常熔断机制**：当数据异常或决策置信度低时，自动升级至人工处理
5. **审计追踪**：所有决策需记录依据和数据来源，便于复盘
6. **权限隔离**：不同岗位 Agent 访问的数据范围和操作权限需严格隔离
