# 跨境 ERP 功能全景调研

> 调研日期：2026-06-25 | 来源：马帮ERP、店小秘、领星ERP、积加ERP、船长BI 官网及帮助文档

## 调研范围

覆盖 5 家主流跨境电商 ERP，按 9 大功能模块逐一拆解到子界面和操作项。

| ERP | 定位 | 核心优势 |
|-----|------|---------|
| **马帮** | 全流程 ERP | TMS/WMS/SCM 全链路，1700+物流，800+海外仓 |
| **店小秘** | 轻量多平台 | 70+平台，180万+卖家，新手友好 |
| **领星** | 精细化运营 | 29+预警模型，全流程广告管理，BI驾驶舱 |
| **积加** | 大客户私有化 | 独立部署，业财一体，积加AI，开放平台 |
| **船长BI** | 数据+AI驱动 | AI诊断+一键执行，80+报表，CPS站外推广 |

## 一、订单管理

### 子界面清单

| 界面 | 功能 |
|------|------|
| **待审核** | 审核订单、标记异常、拆分合并、修改地址/物流 |
| **待处理** | 缺货标记、问题件处理、联系买家 |
| **运单号申请** | 自动/手动申请、物流渠道切换 |
| **待打单** | 批量打印面单/拣货单/配货单 |
| **已交运** | 物流轨迹跟踪、交运异常处理 |
| **已退款/已搁置** | 原因标记、恢复处理 |
| **手工订单** | 手动创建、批量导入 |
| **规则引擎** | 审单规则、物流规则（按金额/重量/国家匹配）、赠品规则 |

### 操作列

查看详情、编辑、打印面单、申请运单号、标记发货、查看轨迹、改地址、改物流、拆分、合并、搁置、取消。

### 关键差异

- **马帮**：自动打标签、合仓管理（就近发货）、全自动拦截问题订单
- **店小秘**：波次发货流程（波次生成→扫描包装→扫描出库→异常包裹）
- **积加**：全渠道概览（Amazon VC、Walmart、Ozon、Wildberries 统一）

## 二、商品管理

### 子界面清单

| 界面 | 功能 |
|------|------|
| **产品管理** | 商品列表、批量编辑、复制、上下架 |
| **数据采集** | 1688采集、链接采集、分类采集、插件采集 |
| **数据搬家** | 跨平台跨店铺复制 Listing、批量修改 |
| **图片管理** | 图片空间、AI白底图、批量水印/裁剪/尺寸标准化 |
| **AI描述** | AI生成标题/描述/关键词、SEO优化 |
| **一键翻译** | 标题/描述多语种、图片文字翻译 |
| **Listing优化** | 质量评分、关键词/图片优化建议 |

### 核心模型

```
SPU（标准产品）→ SKU（库存单位）→ 平台SKU（按平台映射）
```

一个 SKU 可关联 Amazon ASIN、Shopee Variant ID、Lazada SellerSKU 等。

### 关键差异

- **马帮**：违禁词检测/替换、爆款/滞销款自动分类、选品开发
- **领星**：新品管理、产品表现同比/环比分析

## 三、采购管理

### 子界面清单

| 界面 | 功能 |
|------|------|
| **采购建议** | 备货建议（安全库存/最小备货量）、缺货建议、无库存建议 |
| **采购计划** | 购物车式选品、汇总生成、审批 |
| **采购订单** | 草稿→待审核→已审核→部分到货→已完成 |
| **1688采购** | 一键下单、绑定运单号、申请付款 |
| **供应商管理** | 供应商列表、KPI考核、价格/交期历史 |
| **采购统计** | 采购员绩效、采购金额、降本统计 |
| **采购变更单** | 数量/价格变更、变更审批 |

### 关键差异

- **店小秘**：5种备货策略（安全库存/客单量系数/销售系数/库存下限/无库存）
- **马帮**：科学采购计算（随销量自动计算）、库存周转<15天
- **积加**：供应商协同（供应商端登录查看确认）、装配计划

## 四、仓储/库存管理

### 子界面清单

| 界面 | 功能 |
|------|------|
| **商品管理** | 单个/组合/加工/多变种 SKU、导入/导出、分类 |
| **仓库清单** | 库存数量、变动记录、锁定库存 |
| **分区/库位** | 仓库分区、库位码、扫码找货 |
| **入库管理** | 采购入库、退货入库、盘盈入库 |
| **出库管理** | 销售出库、调拨出库、盘亏出库 |
| **库存盘点** | 创建盘点单、PDA扫码盘点、差异调整 |
| **库存调拨** | 仓库间调拨、在途跟踪 |
| **库存预警** | 下限/上限/库龄预警 |

### 5种仓库配置方式

1. 基础流程（SKU少/新用户）
2. 热销SKU优先加仓
3. 商品配对→一键生成（SKU规范）
4. 导入仓库清单（批量）
5. 从订单创建→自动配对

### 关键差异

- **马帮WMS**：PDA无纸化拣货、14种发货模式、智能推荐库位、准确率99%
- **领星**：集成FBA仓/海外仓/本地仓/在途统一管理、29+预警模型
- **积加**：头程发货管理（FBA头程）、物流费用管理

## 五、财务/结算管理

### 子界面清单

| 子模块 | 界面 | 功能 |
|--------|------|------|
| **财务管理** | 账号管理 | 收款账号、平台绑定 |
| | 付款审批 | 采购/物流付款、多级审批 |
| | 收款管理 | 回款记录、收款认领 |
| | 收支明细 | 全部流水、筛选导出 |
| **利润管理** | 利润核算 | 订单/SKU利润、多平台对比 |
| | 物流对账 | 运费账单核对、差异标记 |
| | 平台费用 | 佣金/费率设置、历史 |
| **平台结算** | 结算导入 | 平台结算单、差异核对 |
| | 平台利润 | 各平台专项利润报表 |
| **辅助** | 汇率管理、PayPal、Payoneer | |

### 利润公式

```
利润 = 订单收入 - 平台佣金 - 物流费 - 采购成本 - 广告费 - 其他费用
```

### 关键差异

- **马帮**：业财一体（金蝶对接）、老板报表
- **积加**：FIFO批次成本、全链路循环（正向+逆向+异常）、多维度利润看板、助力IPO合规
- **船长BI**：VAT智能算税、财务核算
- **领星**：资金流追踪（下单→付款→发货→结算→回款全链路）

## 对 LingMirror 的启示

### 已覆盖（Go 新栈已有）

- 商品管理（基础 CRUD）
- 订单管理（基础）
- 平台集成（Ozon/Shopee adapter）
- RBAC 权限
- AgentOS 决策引擎

### 明显缺口（Go 新栈没有或很弱）

| 模块 | 状态 | 影响 |
|------|------|------|
| **采购管理** | 完全没有 | 无法支撑采购流程 |
| **仓储/库存** | 基础库存，无库位/调拨/盘点 | 无法管理实物库存 |
| **财务/结算** | 无利润核算、无平台结算 | 客户看不到真实利润 |
| **客服管理** | 完全没有 | 客服工作无法在系统内完成 |
| **数据报表** | 基本没有 | 无法做运营决策 |
| **物流对账** | 无 | 运费差异无法追踪 |

### 核心结论

> 竞品在拼"功能广度"（马帮）或"运营深度"（领星/积加）。
> LingMirror 的差异化应该是：**用 AI Agent 把竞品需要人工操作的流程自动化**。
> 但前提是——基础 ERP 功能要够用，否则 Agent 无事可做。
