吸收后的设计变化

1. 自治等级成为总控台核心。用户不只是看 Agent 任务，还要能看到每个 Agent 当前像“实习生、助理、主管、资深运营”一样处在哪个自治阶段。

2. 总控台不仅显示业务指标，还显示信任状态。每个小队要展示采纳率、置信度、待审批、被红线拦截、是否可晋升。

3. 第一版做 AgentOS 外壳，但预留桌面 Agent 产品模式。包括上下文引用、技能沉淀、定时任务、IM 审批、动态模型路由，不过第一版只做必要入口和数据结构，不一次做完整生态。

第一版必须落地

  • 全业务总控台首页
  • 统一任务队列和审批队列
  • 三大 Agent 小队分组
  • Agent 自治等级总览
  • 安全红线和高风险动作拦截

第一版先不做深

  • 完整 IM 双向审批
  • 技能市场和自动技能生成
  • 多模型自动路由后台
  • 所有业务域的全自动执行
  • 移动端完整工作台
