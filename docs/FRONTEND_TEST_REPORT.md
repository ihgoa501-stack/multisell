## 发现的问题

### P1 - 高优先级
1. **运费计算器无匹配渠道**
   - 现象: 计算运费后提示"没有匹配的物流渠道"
   - 影响: 无法实际计算运费
   - 建议: 配置物流渠道数据

### P2 - 中优先级
1. **库存分配模拟数据未加载**
   - 现象: 点击"初始化模拟数据"按钮后无响应
   - 影响: 无法测试库存分配功能
   - 建议: 检查后端API `/warehouses/mock` 接口

### P3 - 低优先级
1. **部分模块无数据**
   - 现象: 订单管理、异常工作台显示"No Data"
   - 影响: 展示效果
   - 建议: 补充演示数据
