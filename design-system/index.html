无障碍设计

WCAG AA

本设计系统遵循 WCAG 2.1 AA 标准，确保所有用户（包括视觉、听觉、运动或认知障碍用户）都能平等使用。

颜色对比度

品牌色 500 on white 5.4:1 ✓
中性色 700 on white 7.1:1 ✓
错误色 500 on white 4.7:1 ✓
白色 on 品牌色 500 5.4:1 ✓

键盘导航

✓ 所有交互元素可通过 Tab 键访问
✓ 焦点指示器清晰可见（2px 品牌色外框）
✓ 逻辑 Tab 顺序与视觉顺序一致
✓ 支持 Enter/Space 激活按钮
✓ 支持 Esc 关闭模态框

触控友好

✓ 最小触控目标 44×44px
✓ 行间距足够（1.5 行高）
✓ 支持 200% 文字缩放不破坏布局
✓ 尊重 prefers-reduced-motion 设置
✓ 所有图标按钮配有 aria-label
